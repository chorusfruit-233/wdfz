# 巡察、手机网络与《网安仙人》截图

这些截图来自 PR #29 的本地 Chromium 软件 WebGL，使用流畅画质。由 `python tools/network_screenshots.py` 布置设备、位置和任务状态后，通过实际页面输入显示界面，并把正式 3D 演出推进到指定镜头。不是自然收集通关，也不是 Android 实机截图。

| 截图 | 检查内容 |
| --- | --- |
| [桌面终端](01-桌面终端.png) | 世界继续运行的提示、只读档案、命令输入、帮助与立即退出 |
| [手机应用](02-手机应用.png) | 电量、无线、定位、同步、容器与原纸飞机入口 |
| [服务器](03-服务器.png) | 室内机柜和逐架熄灭的指示灯 |
| [走廊](04-走廊.png) | 稳定照明和停止活动的巡察者 |
| [档案](05-档案.png) | 3D 屏幕上的部署时间、旧记录与签发矛盾 |
| [校园](06-校园.png) | 普通校园光线收束，没有追加追兵 |
| [竖屏终端](07-竖屏终端.png) | 390 × 844 的触屏布局 |
| [短屏终端](08-短屏终端.png) | 390 × 340 的可见窗口：模拟软键盘压缩后仍能退出、执行与查帮助 |
| [竖屏手机](09-竖屏手机.png) | 应用按钮和收起按钮 |
| [竖屏档案](10-竖屏档案.png) | 竖屏使用独立排版，避免横向档案文字被裁切 |

截图参数见[截图记录](截图记录.json)。移动端自动化使用触摸点击与可视窗口尺寸变化，不能证明实体软键盘、性能或听感已通过。
