# 测试截图

每轮改动的测试截图按轮次放在子文件夹里，文件名写清楚拍的是什么。截图来自本地无头 Chromium 的软件渲染（800×450），画面比实机暗、帧率低，只用来核对画面内容。

- [第三轮](第三轮/)：光影、雨天蛾群、巡察者造型、车和树的细节
- [第三轮评审](第三轮评审/)：同一教室在不离开房间的情况下从流畅切换到均衡，窗光即时出现。
- [黑色蛾群](黑色蛾群/)：蛾群及其掉落粉尘的颜色调整。
- [清华水杯](清华水杯/)：新异象——四楼窗台上的保温杯、下落时地上的影子、落地摔瘪、留下的痕迹。

- [产品对齐修复](产品对齐修复/)：重载后的亮度滑块与熄灯后的地点提示。
- [产品对齐决定](产品对齐决定/)：异象选择的五秒倒计时与超时提示。

- [宣传片](宣传片/)：宣传片各段的画面（建筑、异象、玩法、片名）。成片见 [video/trailer.mp4](../video/trailer.mp4)。
- [手写清单第三批](手写清单第三批/)：手机纸飞机、请假中、拍肩前的脚步声、回头看见的笑脸、不回头的突脸。
- [界面重构](界面重构/)：新的状态卡、随身手册（背包 / 地图）、选择框、暂停与设置卡片，手机横竖屏的操作布局，楼梯扶手修复。
- [第七轮评审](第七轮评审/)：320 像素竖屏与矮竖屏快捷栏、手册转暂停后的恢复、钟楼末圈的平台开口；截图使用各自标注的视口尺寸。

- [穿模与超精细](穿模与超精细/)：远端 PR 原有的室内外模型修复前后证据；不包含已撤回的双引擎方案截图。
- [引擎重构](引擎重构/)：最终单一 Three.js 路线，教室与校园在相同机位的重构前后三档和新增超精细；960×540，软件 WebGL，固定场景测试。
- [建模重写](建模重写/)：建模内核重写前后同一机位（固定随机数、关贴图）的画面和放大 10 倍的差异图，教学楼走廊和教学楼外的带贴图对比，门洞过梁两面重合换绘制顺序就变色的问题。
- [建模写实](建模写实/)：建模写实化前后同一机位对比（教室、走廊、宿舍上下铺、厕所瓷砖、车库轿车、食堂、楼的窗户、宿舍楼顶、叶片树冠、车棚电动车、握手电的手），超精细档 Babylon 引擎下的效果，流畅档的简化版本。
- [恐怖氛围](恐怖氛围/)：同一机位白天 / 夜里、加强前后的对比（教室、黑板上的粉笔字、走廊、吊顶破洞、宿舍霉斑、厕所、楼梯口、车库、操场），夜里打着手电，走廊尽头站着的人影。

- [AI 测试攻略](AI测试攻略/)：本地启动游戏后进入教室的截图；960×540，无头 Chromium、SwiftShader、流畅画质，前情已跳过并冻结游戏。
- [重构与精细化](重构与精细化/)：第一人称手部改前改后（手电、手机、手电雨伞手机同时拿着），握手电和拿手机的六视图，六种人形改前改后；1000×700 或棚拍视图，软件 WebGL。
