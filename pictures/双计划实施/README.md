# 双计划实施画面记录

由实际游戏页面条件布置后渲染，工具为 [`school_sensory_preview.py`](../../tools/school_sensory_preview.py) 和 [`sensory_motion_probe.py`](../../tools/sensory_motion_probe.py)。[参数记录](画面记录.json)列出房间、机位、脚高、朝向、内部状态与资源计数；[验证说明](../../docs/validation/双计划实施/README.md)记录测试边界。

| 画面 | 用途 |
| --- | --- |
| [教室前后门](教室前后门.png) | 本人教室走廊侧，装备并开启手电观察两扇独立门；照明保持游戏实际效果。 |
| [本人座位面向黑板](本人座位面向黑板.png) | 西向教室，黑板、讲台、课桌及座位相对关系。 |
| [100](感官-100.png) / [45](感官-45.png) / [22](感官-22.png) / [8](感官-8.png) / [关闭扭曲](关闭扭曲.png) | 同机位、内部状态值逐档及关闭对照；这些数值仅用于开发记录，不显示在玩家 UI。 |
| [楼梯下跑](真实楼梯下跑.png) / [半层平台](真实楼梯半层平台.png) | 真实踏步、双跑结构和扶手。 |
| [二楼门槛](二楼出口连续视野.png) / [车库校园出口](车库楼梯校园出口.png) | 梯间看向相邻场景，无黑屏切换。 |
| [320×640](触屏字幕-320x640.png) / [390×844](触屏字幕-390x844.png) / [844×390](触屏字幕-844x390.png) | 浏览器触屏仿真、字号 150%、静音字幕常开，保留触控按钮。 |
| [12 秒动态对比](感官动态对照.mp4) | 每段 2.4 秒：正常 → 低状态标准 → 低状态减弱 → 低状态关闭 → 恢复。 |

静态场景为 1000×700、流畅档软件 WebGL；动态为 640×360、10 fps、无音轨，逐帧推进表现时钟，不推进游戏玩法。手机项使用表中分辨率。视频中的切换是受控 A/B，不代表玩家自然下降的速度；静态图也不足以判断眩晕和恐惧感。高画质资源切换另见[机器记录](../../docs/validation/双计划实施/感官动态与资源.json)，并非实体设备性能验收。
