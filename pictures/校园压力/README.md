# 校园压力草稿的浏览器验证

这些截图来自草稿 PR #14 的无头 Chromium + SwiftShader 软件 WebGL，桌面 1000×700、触屏模拟 390×844。

| 文件 | 场景与操作 |
| --- | --- |
| [桌面课堂](桌面课堂.png) | 开始游戏后按 R 打开课桌任务，真实点击选项并使用键盘离座，课堂时间继续。 |
| [触屏课堂](触屏课堂.png) | 触屏模拟中点按「看课桌」与「放下」，检查关闭后恢复输入。 |
| [低 SAN 身体反应](低SAN身体反应.png) | 条件布置为 SAN 8，状态显示「快撑不住了」，体力上限 44.8，正常 HUD 无 SAN 数值条。 |
| [巡察者锁定](巡察者锁定.png) | 条件布置巡察追逐，将游戏亮度设置到 150 观察轮廓，记录停顿后短距离瞬移；保留红色锁定反馈，移除红眼。 |
| [条件布置的传送门结局](条件布置的传送门结局.png) | 准备位置、状态与材料后，经真实选项完成传送门结局；不是自然收集材料通关。 |

[浏览器验证.json](浏览器验证.json) 记录实际得到的时间推进、任务完成、体力上限、瞬移前后位置和结局状态。复现命令（仓库根目录）：

```bash
PYTHONPATH=tests python tools/pressure_preview.py
```

脚本使用独立浏览器上下文与临时站点，不访问玩家常用浏览器存档。低 SAN、巡察者和传送门部分通过场景布置触发。未自然游玩完整约 44 分钟的一天，也未进行真机、音乐听感或异地联机评估；截图与自动化不能替代这些体验检查。
