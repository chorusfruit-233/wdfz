# 调试面板界面验证

> 本组保留当时的界面和测试取图方式；之后主线已换为页内数字密码键盘、加入 Mod 页签并改进横屏布局。当前操作与巡察调试语义以[调试面板说明](../../docs/调试面板说明.md)为准，不用旧截图推断现有功能。

截图来自本地无头 Chromium 和 SwiftShader。游戏已开始，前情已跳过；截图时冻结自动推进以便观察界面。密码提示框由测试替代输入，原密码校验由自动化测试单独覆盖。
