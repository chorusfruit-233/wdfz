# 调试面板界面验证

截图来自本地无头 Chromium 和 SwiftShader。游戏已开始，前情已跳过；截图时冻结自动推进以便观察界面。密码提示框由测试替代输入，原密码校验由自动化测试单独覆盖。

| 截图 | 视口和操作 |
| --- | --- |
| [桌面状态](桌面状态.png) | 1000 × 700，键盘 F2 打开，显示状态与调试暂停。 |
| [竖屏场景](竖屏场景.png) | 390 × 844，触屏模拟，从暂停菜单打开并筛选室内地点。 |
| [横屏事件](横屏事件.png) | 844 × 390，触屏模拟，从暂停菜单打开事件页并向下滚到死亡效果。 |

截图和触屏模拟不能替代实体手机测试。可用 `PYTHONPATH=tests python -m unittest -v test_dev_panel` 复测布局、触屏操作和存档边界。
