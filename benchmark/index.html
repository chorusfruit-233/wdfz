WebGPU / WebGL

用相同画质、分辨率和固定镜头，比较这台设备连续渲染的吞吐与帧间隔。游戏存档、设置和成绩保持独立。

测试场景

显示画布抗锯齿统一关闭，场景抗锯齿跟随画质。每场景先预热 2 秒、至少 3 帧；采样不含加载。两轮按 GL → GPU、GPU → GL 运行。默认约需 2 分钟，慢设备会更久。请保持本页在前台。

这些数字怎样理解

连续渲染允许 CPU 与 GPU 并行，最多有两帧尚未完成。吞吐将采样尾部的 GPU 等待也算入总时间，避免把排队提交误算为已经完成的帧。P95 帧间隔反映提交节奏；两项都受浏览器调度和屏幕刷新率影响。

逐帧同步诊断在每帧等待 GPU 完成，用来分析提交与完成等待的差异。它会打断渲染流水线，不能用其差值推算游戏帧率。两种模式都不是纯 GPU 时间，也不包含游戏逻辑、HUD 和声音。

测试冻结剧情、巡察、随机异象和镜头，不计加载与编译。实际分辨率、MSAA、场景指纹、显卡信息和原始帧写入导出报告；规格不同或样本过少时不判优。没有 WebGPU 或中途回退时不会冒充 WebGPU 成绩。

功耗、温度和真实 GPU 内存字节数未测。不同浏览器、驱动和设备的结果不能直接混比。完整测试口径
