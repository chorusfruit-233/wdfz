01 / GETTING STARTED

初次进入

这是单人第一人称校园怪谈探索游戏。你从教学楼一楼的座位上醒来，起始时间是第一天的 11:40。留意钟表、课表和字幕，探索校园，寻找能离开的方法。

01 / 生存

遵守当前时段的要求，留意 SAN、体力与违规。

02 / 探索

走近门、楼梯或物件，按交互键查看。翻找课桌与柜子。

03 / 记录

查看地图、笔记和「思索」。找到线索后，新的办法会出现。

游戏有两种难度，每次开局会随机获得一项天赋；暂停菜单会显示名称与描述。

难度区别
预知梦异象间隔较长，SAN 消耗较低；第一天死亡后最多三次在 11:40 的座位上惊醒，背包与已获线索保留。第二天或次数用尽后死亡仍会结束。
梦魇没有惊醒机会；异象更频繁，SAN 消耗和部分错误选择的代价更高，危险异象也更快致命。

首次游玩可选择「预知梦」熟悉环境。异象应对与结局步骤在页面下方的折叠区，打开前可自行避开剧透。

03 / SURVIVAL

生存与课表

观察三种状态

  • SAN：左上方的条代表精神状态。归零会死亡。按课表待在合适的位置、利用恢复设施或药片，可以回复 SAN。
  • 违规：需要在教室、操场或宿舍的时段，长期不在要求的位置会累积违规；回到要求的位置会逐渐降低。达到上限会死亡。
  • 体力：奔跑会消耗体力，停跑后恢复。跑空后体力条变红，要恢复到三分之一左右才能再跑。

上课和晚自习时，回教学楼一楼教室坐下可回复 SAN、降低违规；课间操时优先去大操场或跑道，独立篮球场目前不计入操场判定；熄灯后回南、北宿舍。自由时段适合探索，但车库、垃圾房和夜间室外仍会额外消耗 SAN。

长期按部就班也会带来变化：注意角色的自言自语，必要时离开座位或宿舍活动。不要把高 SAN 当成完全安全。

保存与继续

进出房间、预知梦惊醒时会自动保存；也可以暂停后选择「保存进度」。主菜单的「继续上次」读取最近一次存档。真正死去（梦魇模式，或预知梦次数用完）或达成非假结局后，存档会被删除；假结局保留存档，可选择醒来继续。拿到过的结局会记在主菜单上。存档保存在当前浏览器的本地数据中；更换设备、浏览器或清除网站数据后，原存档可能无法使用。

巡察者 玩法剧透

上课、考试的时候，如果你不在自己的座位上，教学楼、行政楼、实验楼里会来一个很高的「巡察者」；校长办公室里它一直在；夜里它也会在室外走。它来之前，屋里的灯会「两短一长」地按节拍闪。它看见你一会儿，灯就会一下子全红——它锁定你了，比你走路快，被它碰到就死。

  • 跑出它的视线一会儿，它会跟丢。
  • 提前躲进走廊或办公室里的储物柜（再按一次 E 出来）。被它看着钻进去的话没用。
  • 被盯上以后，背对它、一动不动站满两秒多，它会从你身边走过去。很难，但能活。
  • 口袋里有符纸时，它锁定你的那一刻符纸会替你挡一次。

考试模式 玩法剧透

在钟楼顶上撞响那口钟后，当天剩下的课和晚自习都会变成考试，持续到熄灯：离开座位扣 SAN、涨违规都更快，异象只会出现教室里的那几种；每场考试大部分时间坐在自己座位上，交卷时回复 15 SAN。

04 / CAMPUS

地点与设施

按 M 或点「地图」查看校园及自己的朝向。建筑的一楼出口可回到室外；靠近楼梯交互可上下楼。教学楼、实验楼和行政楼之间有二楼连廊。

地点可留意的事
教学楼一楼是起点，有教室、课桌和厕所；楼梯通往其他楼层与天台。课桌可以翻找，座位可以坐下。
实验楼 1F–5F依次有物理、化学、机房、地理和音乐教室。物理单摆可预报下一次异象；地理挂图可以标记线索地点，地球仪底座藏有罗盘。
行政楼办公室可以搜寻线索；三楼有数据终端。
保安岗在北门附近，检查柜台下方：钥匙已经上交到校长办公室了，但抽屉里有手电筒；背包满时清出空位后可以重试。
行政楼 5F · 校长办公室车钥匙和机房钥匙有机会从这里的抽屉、柜子里翻到，别的老师办公室偶尔也有。也能翻到建筑总览图和不知名药丸。巡察者常驻，异象也来得很勤；背包满时先腾出空位再翻。
地下车库黑暗且危险，可从北侧车道或行政楼西侧人行口进入。带上光源并注意周围脚步。
食堂 / 宿舍饭点在食堂吃饭免费；饭点以外投一枚硬币也能买到热饭。食堂东墙边的售货机一枚硬币换一样东西（偶尔是符纸、药丸，也会吞币）。在宿舍床边休息可以恢复 SAN，但会消耗游戏时间。
钟楼 / 垃圾房钟楼一楼有供桌，中间的旋转楼梯绕着石柱走两圈到顶，钟挂在顶层平台上；垃圾房位于校园东南侧。两处都值得仔细观察。
操场、球场与花园在相应区域互动，可跑步、投球或看远处来恢复 SAN，并消耗一些游戏时间。

恢复活动有冷却时间：例如吃饭回复 18 SAN、休息回复 26 SAN；完成时还会恢复部分体力。音乐教室的钢琴和教学楼的洗手台也有恢复互动。

机房小游戏：电脑可进入贪吃蛇，玩的时候校园里的时间暂停，整个活动只算 15 分钟。键盘可用 WASD / 方向键操作，按 Esc 或点击「退出电脑」离开；手机上用屏幕右下角的方向键或在画面上滑动转向，点右上角「✕ 退出」离开。

05 / INVENTORY

道具与线索

背包最多容纳 8 种物品，相同物品不会重复放入。桌子、抽屉和柜子的搜索结果多数是随机的，空的也很常见。搜索前留出空格：已经翻过的容器不会重新刷新，部分固定物品也只检查一次。

道具用途
手电筒 / 手机分别提供较强 / 较弱的光源。车库里的东西可以被持续照射暂时逼退。
雨伞使用后撑开，可在暴雨中遮挡雨水；再次使用收起。
药片 / 士力架使用药片回复 18 SAN；士力架让你 10 秒内疾跑不耗体力。使用后消耗。
笔记本 + 笔同时携带时，部分记下的线索可以跨天保留；没有两者时，这些线索只能在发现当天回忆。已发现的地点仍会记录。
粉笔 / 笔可用来处理被划掉的名单，不会因这一操作被消耗。
平面图 / 纸条使用后可记下相关地点或路线提示；平面图也会打开校园地图。
罗盘室内指向附近的门、出口或楼梯；室外指向未记录的线索点，全部记录后指向最近的校门。提示方向和大致距离。
硬币食堂买饭、投售货机；在车库中使用会朝面向方向扔出。
铜线圈 / 透镜 / 荧光试剂传送门材料：网络中心的服务器、物理实验室的显微镜、化学实验室的离心机。
建筑总览图标出所有关键地点，并圈出校长办公室、物理实验室和钟楼。
不知名药丸 / 符纸自动生效：药丸在你要死的时候救你一次；符纸在巡察者锁定你时替你挡一次。
作业本在特定异象中可以递出去，让对方安静下来并回复 SAN。
机房钥匙 / U 盘 / 车钥匙与上锁的网络中心、门禁终端和车库有关。具体用法见下方结局攻略。
手表 / 护目镜带着手表时，右上角会显示精确到秒的时间；携带护目镜会影响部分实验器材的随机结果。
校服外套 / 电池 / 节拍器可查看物品说明；当前版本中没有可依赖的单独主动效果。

「思索」列出根据地点想到的办法；「笔记」展示已注意到的地点和部分线索。并非每个想到的办法都安全。

随机天赋

天赋在开局随机分配。当前版本可确认：编程社可以不用 U 盘操作门禁终端；车感好可以不用车钥匙上车；夜视减轻车库与夜间室外的额外 SAN 消耗；铁胃延长食堂盛宴的危险等待时间；瘦小扩大垃圾桶路线的时间窗口；秒表让右上角一直显示精确到秒的时间。其他天赋可在暂停菜单查看介绍，遇到危险仍应及时避开。

06 / ANOMALIES

异象图鉴

异象随地点和时间出现。低 SAN、高违规可能让它们来得更频繁；一些异象结束后会留下痕迹。看清字幕再决定是停下、移动还是离开。

展开 23 种异象及应对方法 玩法剧透

下列前六种可能直接致命；其他异象仍可能扣除 SAN 或增加违规，导致间接死亡。危险阈值在梦魇难度下更紧。

异象应对
下不完的雨尽快进屋、站在屋檐 / 柱廊 / 车棚 / 连廊下，或撑开雨伞；长时间淋雨会致命。
蛾群远离蛾群出现的位置；停留过久会致命。
操场做操的人离开人群出现的位置；靠近过久会被卷进去。
实验楼仪式现场不要进入粉笔圈；已经踩进去就立刻离开。
围墙外的行人远离东围墙和跟随的身影，别继续靠近。
天台的第二个你看着他时他会停下；朝楼梯撤退并离开天台。不要让他靠近。
有人拍肩选择「不回头」并等待；回头会损失 SAN。
广播点名按广播要求停下，直到广播结束。
钟敲十三下坐回教学楼一楼的座位，或爬上钟楼顶撞钟抵消；否则会损失 SAN。
车棚所有铃一起响远离车棚，避免在附近久留。
隔间底下伸来的手选择「不动」；把手放上去会损失 SAN，还可能失去一件背包物品。
你作业交了吗有作业本可以递出去；不出声也能等它结束，但会损失少量 SAN。说出名字代价更高。
黑板上的「下一次」记下出现的时间，异象结束前会缓慢损失 SAN。
无尽的走廊不要慌，等待即可结束；使用奔跑可加快结束。
被划掉的名字在名单附近交互；有笔或粉笔可写回名字，没有时可撕掉或用指甲刻回。放任不管会增加违规。
天花板渗水避开水渍和滴水处，不要站在下面。
冷库选择把门拉开一条缝会回复 SAN；转身离开会损失 SAN。
窗外的楼在动异象期间会缓慢损失 SAN，等待其结束。
全体回头保持移动；站住太久会损失 SAN。
熄灯后的走廊灯继续移动；在灯下停住太久会损失 SAN。
食堂的盛宴及时离开食堂；停留过久会损失 SAN 并消耗游戏时间。
影子慢一拍进屋、躲到遮挡处或撑开伞，不要在露天久留。
雨点落成的字等待字迹出现；期间会缓慢损失 SAN。

车库中的跟随者是独立危险，并非上表的随机异象：用手电筒或手机持续照向它可以让它暂时消失，注意它之后还会回来。

07 / ENDINGS

结局与逃生路线

游戏中有五个结局：其中《门》是真结局，《第三个桶》是假结局。每个结局都有一段实时演出，点击或按空格可以跳过。寻找地点和物品、留意环境中的文字与笔记，再选择适合自己的路线。以下步骤包含完整解法。

《闸门》：车库路线 结局剧透
  1. 去行政楼五楼的校长办公室翻出车钥匙（小心巡察者），再到保安岗拿手电筒。
  2. 前往地下车库。车道上的东西比你跑得快，靠近时用光照着它，直到它消失。
  3. 车库里有 16 辆车，只有一辆能开，而且在离入口远的那一半里。一辆辆试：每次要站着拧一会儿钥匙，它会趁机靠近，试过的车会记下来。
  4. 找到那一辆、它又不在附近时发动，就能开出去。「车感好」天赋可以不带车钥匙。
《白名单》：门禁路线 结局剧透
  1. 去行政楼五楼的校长办公室翻出机房钥匙。
  2. 进入实验楼三楼机房，打开东侧上锁的网络中心。在里面搜索货架取得门禁 U 盘，再使用门禁管理终端。拥有「编程社」天赋时可省去 U 盘。
  3. 前往行政楼三楼，使用数据终端同步白名单。
  4. 去校园西侧的西小门，靠近闸机交互，即可触发结局。

先给背包留空位；网络中心的货架翻过后不会重新刷新。

《第三个桶》：垃圾房路线（假结局） 结局剧透
  1. 找到校园东南侧垃圾房，查看桶盖上的清运时间提示。
  2. 普通情况下，在游戏时间 17:30–17:36 期间与桶交互可触发结局；尽量在 17:36 前完成。「瘦小」天赋将窗口扩大到约 17:28–17:38。
  3. 清运窗口开始前 40 个游戏内分钟内，也可以交互选择「钻进去，等」；会损失 12 SAN，然后进入结局。

时间太早时先不要钻；熄灯后钻进去会致命。垃圾房内也会额外消耗 SAN，注意不要提前等得太久。

这是假结局：看完可以选「……再睁开眼」，你会在第二天早读的座位上醒来，东西都还在；之后垃圾桶不再是出口。

《先辈》：第三个隔间路线 结局剧透
  1. 先找到一件可以丢弃的物品，前往教学楼一楼厕所，查看第三个隔间门上的刻字「11:45:00　放下一样东西」。
  2. 时间要精确到秒：带上手表（或天赋为「秒表」），右上角会显示时分秒。
  3. 在 11:45:00–11:45:10 之间，在厕所里从背包丢下一件物品（G），即可触发结局。这 10 秒钟时间会慢下来，大约有 15 秒的真实时间。
  4. 开局 11:40 醒来后立刻跑过去来得及；错过了可以等第二天第四节再试。
《门》：传送门路线（真结局） 结局剧透
  1. 到实验楼一楼的物理实验室，查看实验台上的草图，记下四样材料。
  2. 铜线圈：校长办公室翻出机房钥匙 → 实验楼三楼网络中心，交互服务器。
  3. 透镜：物理实验室的显微镜。荧光试剂：二楼化学实验室的离心机，甩成功那一次（失败了等冷却再试）。
  4. 电池：课桌、实验室或售货机里随手能翻到。
  5. 四样都在身上，回物理实验室的实验台组装，走进光圈。

背包满时，清出空位后可回到服务器、显微镜或离心机重试；误丢的三种实验材料也可以回原处重新获取。组装后如果暂时离开，可回实验台再次进入光圈。

危险的「思索」选项 玩法剧透

「从正门走」「翻墙」和「去东围墙等一个路过的人」并非安全出口。要分别站在北门、攀爬点、东围墙底下才能执行，确认后会触发死亡；如果只是想查看，请选「再想想」。

08 / HELP

常见问题

视角不动或鼠标消失了？

先关闭背包、地图、选项和暂停菜单。电脑端点击游戏画面重新尝试鼠标环视，也可以按住画面拖动；触屏直接在画面空白处滑动。切换窗口后如已暂停，先点「继续」。

怎么调整画面和声音？

主菜单可调整画质和亮度；暂停后进入「设置」可调整音量、字幕停留、画质、镜头晃动和音乐 / 环境声。设备运行吃力时可选择低画质。

为什么拿不到东西？

确认已经靠近并面朝目标再按交互键；翻找要站着不动等准星外那一圈走满（约 0.8 秒），走开就会中断。再检查背包是否满了；部分容器可能是空的，而且只能翻找一次。重要物品出现前最好保留空格。

如何在本地游玩？

游戏和 Wiki 均为仓库内的本地文件。下载完整仓库后打开 index.html，或在仓库目录执行 python -m http.server 8000，访问 http://localhost:8000/。

本指南依据当前 3D 版的游戏规则整理；如果游戏更新，请以游戏内实际提示为准。
