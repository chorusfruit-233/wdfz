01 / GETTING STARTED

初次进入

这是一款单人第一人称校园怪谈探索游戏。你在教学楼一楼教室自己的座位上醒来，时间是第一天的 11:40（第 4 节课）。兜里有一张学生证：照片上的人你不认识，班号、学号却都是你的。

01 / 活下去

按课表待在该待的地方，盯住 SAN、体力和违规。

02 / 去探索

走近门、楼梯、桌柜和器材，看准星下方的提示按交互键。

03 / 想办法

翻地图、笔记和「思索」。线索够了，离开的办法会自己冒出来。

难度区别
预知梦异象 40–64 秒一次（真实时间），SAN 消耗较低。第一天死亡后最多三次在 11:40 的座位上惊醒，背包与线索都保留；第二天起或用完三次后，死亡就是结束。第一天不会出现蛾群、仪式、长脖子行人和天台的第二个你。
梦魇没有惊醒机会。异象 24–40 秒一次，SAN 消耗、非致命异象扣的 SAN、危险异象的致死速度都更狠。

每局开始会随机获得一项天赋，暂停菜单里能看到名称和效果。第一次玩会先看一段「前情提要」，点击画面或按空格 / 回车翻页。

建议第一次选「预知梦」。异象应对、特殊事件和结局步骤都放在折叠区里，展开前可以自行避开剧透。

靠近能交互的东西时，准星下方会写出能做什么（「E 开门」「E 坐下」「E 翻找」……）。面前的东西优先：侧面、背后的东西要离得很近才会被选中。翻找要站着不动，等准星外那一圈走满（约 0.8 秒），走开就会中断。

03 / SURVIVAL

生存与课表

四个数值

  • SAN：通过左上角的身体反应、画面失真和音乐变化感知，不再显示数值条。耗尽即死。逃课本身不扣 SAN；异象、危险区域以及躲避巡察者会消耗精神。安全时日常恢复，药片和活动也能补。
  • 违规：该在教室、操场、宿舍的时候不在，违规就涨；回到该在的地方会降下去。17:20–18:10 的晚间活动不计违规，异象的额外记过也不例外；熄灯后即使在宿舍也会涨。违规记满不会死，但班主任会在本子上划一笔，之后请假条批不下来，直到违规降到 60 以下。违规越高，异象来得越密。
  • 体力：奔跑消耗，停下恢复。SAN 越低，体力上限越低；精神恢复后，上限会回升，体力仍需逐渐恢复。跑空后体力条变红，要恢复到三分之一左右才能再跑。士力架起效时，体力条变成金色的倒计时。
  • 同化：看不见的数值。上课坐在座位上、晚上按时回宿舍会让它慢慢上涨，角色的自言自语会越来越不对劲（见特殊事件）。离开座位、在外面走动会让它回落。

守规矩不等于安全。SAN 很高时，也要留意自己说的话是不是越来越像"这里的人"。

上课看课桌

坐在教学楼一楼的座位上，上课时可以按 R 或点状态卡里的「看课桌」，校对课表、查看点名册或读夹在书里的纸条（一共十种，答对的那一句往往是真的有用的提醒）。每节课一次，12 秒内作答；答对能稍微安定下来，选错没有额外惩罚。期间课堂、同化和危险继续运行，异象或巡察者锁定会打断。放下以后本节不能重做，保存再读档也不能重复领奖。

请假

请假条用掉后可以请 两个小时（游戏时间）的假：这段时间不用待在规定的地方，违规不涨，巡察者也不管你。违规记满时批不下来。

保存与继续

进出房间、预知梦惊醒和驾驶通过路口时自动保存，也可以暂停后点「保存进度」。主菜单「继续上次」读取最近的存档。真正死去或成功逃脱后当前存档删除；已经记录的结局保留。存档在当前浏览器的本地数据里，换浏览器或清除网站数据就没了。

04 / PATROL & EXAM

巡察者与考试 玩法剧透

巡察者

上课、考试的时候，如果你不在自己的座位上，教学楼、行政楼、实验楼里会来一个很高的巡察者：过膝长大衣、大檐帽、左臂红袖章、手里夹着点名的夹板。白天校长办公室不论课表都会有它；夜间它只在室外活动。下课或昼夜切换让当前地点不再允许巡察时，预警和追逐都会结束。它没有红眼，靠近时会像车库黑影一样短距离瞬移。

  • 预兆：屋里的灯会「两短一长」地按心跳节拍闪；夜里在室外，路灯也会跟着闪。脚步声从它所在的一侧传来，戴耳机能听出方向。
  • 锁定：它看见你一会儿，灯一下子全红，你会听见自己的心跳。它每次停一会儿，再突然靠近一小段，平均比走路快。利用遮挡或进楼可以甩开；被碰到会死。
  • 甩开：跑出它的视线，跟丢 2.5 秒它就放弃。
  • 躲柜子：提前钻进走廊或办公室的储物柜（再按一次交互出来）。被它看着钻进去没用。
  • 装作没看见：被锁定后背对它、一动不动站满 2.5 秒，它会从你身边走过去。
  • 符纸：口袋里有符纸时，它锁定你的那一刻，符纸会替你挡一次。
  • 它会回来找：跟丢以后，它会先去最后看见你的地方站一会儿再走；你在它盯着你的时候躲过的柜子，它下次出现会先去那个柜子门口停一会儿。只要它没看着你钻进去，就抓不到你。
  • 到不了：被门、桌椅挡住、走不到你身边时，它过一会儿就会放弃，灯会亮回来。

考试模式

在钟楼顶上撞响那口钟，当天剩下的课和晚自习都会变成考试，直到熄灯：离开座位时违规涨得更快，逃课本身不再扣 SAN；异象只会出现教室里的那几种（全体回头、黑板上的字、你作业交了吗、被划掉的名字、窗外的楼在动、广播点名）。一场考完，如果七成以上时间坐在座位上，交卷时回 15 SAN。夜里撞钟没有人回应。

05 / CAMPUS

地点与设施

按 M 看校园地图和自己的朝向。各楼一楼出口回到室外，楼梯上下楼；教学楼、实验楼各有一台电梯，可呼梯等待、进入轿厢并选择 1–5 层，天台仍需走楼梯。教学楼、实验楼、行政楼二楼之间有连廊。有的门锁着，需要钥匙。

地点可留意的事
教学楼一楼是起点：教室、课桌、走廊储物柜和厕所。楼梯通往各层和天台；一楼讲台上有一支粉笔。
实验楼 1F–5F依次是物理、化学、机房、地理、音乐。物理实验室的单摆会预报下一次异象；显微镜、二楼化学实验室的离心机能出传送门材料；四楼地球仪底座藏着罗盘，挂图能标记线索地点；三楼机房的电脑能玩贪吃蛇，东侧上锁的网络中心有服务器和门禁终端。
行政楼办公室能翻找；三楼有数据终端。五楼是校长办公室：车钥匙、机房钥匙在这里的抽屉柜子里（每个容器有 45% 概率给一把未持有的钥匙，连着三个没翻到，第四个一定有；别的老师办公室约 1%），还能翻到建筑总览图和不知名药丸。白天巡察者频繁出现，异象也来得勤。
保安岗北门旁边。柜台下的钥匙钩是空的（钥匙上交到校长办公室了），抽屉里有一把手电筒。
地下车库北侧车道或行政楼西侧人行口进入。漆黑，里面有一个会跟着你的东西。夜视天赋能减轻这里的 SAN 消耗。
食堂饭点（12:15–13:20、17:40–18:10）免费吃饭；其它时间在窗口投一枚硬币也能买到。东墙边的售货机一枚硬币换一样东西，偶尔有符纸、药丸，也会吞币。
南、北宿舍熄灯后要回来；床上能躺一会儿。
钟楼一楼有供桌；旋转楼梯绕着石柱走两圈到顶，顶层平台挂着一口钟。
垃圾房校园东南侧。几个大桶里，第三个不太一样。
操场、球场、花园跑步、投篮、看远处，都能回 SAN。

06 / INVENTORY

道具与天赋

背包最多 8 种物品，同一种只能带一件。抽屉、柜子、货架大多是随机的，空的很常见，翻过一次就不会再刷新。背包满时先腾出空位再翻；翻到已经带着的东西时，它会留在原处，等你不再带着同类物品再回来拿。

道具用途
手电筒光源（F）。车库里那个东西被持续照着会暂时退开。
手机只剩「纸飞机」：点屏幕或按空格往上飘，穿过书架的空隙。一局按得分回 SAN（最多 +6），之后手机发烫 45 秒。玩的时候站着不动、时间照走；有异象或巡察者盯上你时屏幕会黑。
请假条两个小时的假（见上文）。
雨伞撑开 / 收起。撑开能挡雨和「影子慢一拍」，挡不住掉下来的水杯。
药片30 秒内每秒回 2 SAN。
士力架30 秒内奔跑不耗体力。
笔记本 + 笔两样都带着时，想到的事会写进本子，跨天也不会忘。

07 / ANOMALIES

异象图鉴

异象按地点和时间出现，同一种不会连着来，最近出过两次的也会先缓一缓，没见过的更容易来；来之前常常先有一阵压得耳朵发闷的低音。SAN 越低、违规越多来得越密；校长办公室里间隔减半。异象里的选项限时 5 秒，超时会随机替你选。危险的几种（暴雨、蛾群、水杯）出现前会预警；物理实验室的单摆能提前算出下一次是什么。

展开 25 种异象及应对方法 玩法剧透

前七种会直接致死；其余的扣 SAN、加违规或拿走东西。梦魇难度下阈值更紧。

异象在哪应对
下不完的雨室外，非上课时段尽快进屋，或站到屋檐、柱廊、车棚、连廊下，或撑伞。淋久了会致命。
蛾群下过雨之后离开它出现的地方；待得越久越危险。
操场做操的人操场离开人群；靠近太久会被卷进去。
清华水杯贴着教学楼、行政楼、实验楼外墙走时头顶叮当响、看到「它掉下来了」就立刻挪开（落点是你那一刻站的地方），或躲到柱廊、连廊下。伞挡不住。
实验楼仪式现场实验楼不要进粉笔圈；踩进去马上出来。
围墙外的行人东围墙附近远离围墙，别再靠近。
天台的第二个你教学楼天台看着他他就不动；边看着他边退到楼梯下楼。
有人拍了一下任何地方选「不回头」并等它松手（回 SAN、得线索）；回头扣 SAN。如果拍肩前先听见身后的脚步声走近，这次要回头：回头只扣一点，不回头会被突脸、扣很多 SAN 并加违规。
广播点名室内站住别动（坐着也行），等广播说完。
停电楼内楼内灯光会熄灭并持续失去 SAN；可以用手电辨路，离开楼内或等待灯光恢复。
钟敲十三下教学楼、北宿舍回教学楼一楼坐到自己的座位上；或者爬上钟楼顶撞一下钟，两边的钟声抵消，还回 8 SAN。
车棚所有铃一起响车棚附近离开车棚。
隔间底下伸来的手厕所选「不动」；把手放上去会扣 SAN，还会丢一件东西。
你作业交了吗教室递出作业本最好；不出声要等很久并扣一点 SAN；说出名字代价最大。
黑板上的「下一次」室内如果黑板上写出一个时间，记住它：那时会来一个危险的异象。期间慢慢扣 SAN。
无尽的走廊教学楼走廊继续走，跑起来结束得更快；拐进教室或出楼也能结束。
被划掉的名字室内到名单前交互：有笔或粉笔就把名字写回去；没有就撕掉或用指甲刻。不管它会加违规。
天花板渗水室内避开地上的水渍和滴水处。
冷库食堂把门拉开一条缝回 SAN；转身走掉扣 SAN。
窗外的楼在动教室等它结束，期间慢慢扣 SAN。
全体回头教室保持走动；站住太久会扣 SAN。
熄灯后的走廊灯夜里的教学楼走廊一直走；在灯下停住太久会扣 SAN。
食堂的盛宴饭点的食堂尽快离开；待久了扣 SAN 并丢掉 20 分钟。
影子慢一拍操场进屋、躲到遮挡下或撑伞。
雨点落成的字下过雨之后等字写完，期间慢慢扣 SAN。

车库里跟着你的东西不在上表里：用手电一直照着它会退开，过一阵又会回来；扔出硬币能把它引开。

08 / EVENTS

特殊事件

学生会检查 玩法剧透

每天 12:50 和 17:50 有检查，需要待在教室。检查前几分钟校园广播会提醒，状态卡上的时段也会显示「教室（学生会要来）」。黑影出现后保持静止，避免注视；移动会增加违规，注视黑影会持续损失 SAN。17:50 的检查违规仍然生效。到点时如果你正被别的事拦着（比如在电梯里），过一会儿这场检查就不来了。

第二天：一切都正常了 剧情剧透

第一天熄灯后，口袋里会多一张纸条：「灯前看字字如旧，月下认人人已非。——笑时莫出声。」

到了第二天，颜色回来了，到处是看起来很正常的人和事。每隔一会儿会遇到一件「看起来」很正常的事，让你选笑一下还是不笑。每次笑都会让你离那边更近一步，笑得太多就再也停不下来。照纸条说的做：别笑出声。熬过四件，天就黑了。

同化：位子一直空着 剧情剧透

一直乖乖坐在座位上、按时回宿舍，同化值就会涨，自言自语会越来越像这所学校里的人。同化满值会直接融入学校、死亡，没有「回教室去」的脱身选项。药丸、免疫或预知梦等现有救命机制仍可生效。

经常离开座位、四处走动可以让同化值降下来。第一天一直坐着上课还撑得住，第二天早上再这样坐满就会出事；听见自己说「椅子不让我起来」的时候，站起来走走。

危险的「思索」 玩法剧透

「从正门走」「翻墙」「去东围墙等一个路过的人」都不是出口。要分别站在北门、攀爬点、东围墙底下才能执行，确认后会死。只想看看的话选「再想想」。

09 / ENDINGS

结局攻略

以下列出公开的逃脱与失败路线。《闸门》《白名单》《门》为真结局；垃圾桶是死亡分支。结局演出可点击或按空格跳过。

《闸门》：车库路线 结局剧透
  1. 去行政楼五楼校长办公室翻出车钥匙（小心巡察者），再去保安岗拿手电筒。
  2. 进地下车库。车道上的东西比你快，靠近时用手电照着它，直到它退开。
  3. 车库里有 16 辆车，只有一辆能开，在离入口远的那一半里。一辆辆试：每次要站着拧一会儿钥匙，它会趁机靠近；试过的车会记下来。
  4. 找到那一辆、它又不在附近时发动。「车感好」可以不带钥匙。
  5. 开场演出后亲自驾驶：W / ↑ 加速，A D / ← → 转向，S / ↓ 刹车；触屏推动摇杆。避开路障，按路标选择方向，驶出足够距离才能逃脱。过于缓慢会被追上。
《白名单》：门禁路线 结局剧透
  1. 校长办公室翻出机房钥匙。
  2. 实验楼三楼机房，打开东侧上锁的网络中心；翻货架拿到门禁 U 盘，用门禁管理终端把自己加进白名单（「编程社」不用 U 盘）。
  3. 行政楼三楼的数据终端同步。
  4. 去校园西侧的西小门闸机，完成三道验证题后通过（高中各科的基础题）。答错会损失一点 SAN，并换成另一道题；暂时离开后进度会保留。

先给背包留空位；网络中心的货架翻过就不会刷新。

第三个桶：垃圾房路线 剧情剧透

垃圾房第三个桶不是出口：钻进去会触发死亡，仍可由通常的救命机制保护。垃圾房里也会持续消耗 SAN。

《门》：传送门路线（真结局） 结局剧透
  1. 去实验楼一楼物理实验室，从实验台后进入隧道；隧道里会持续消耗 SAN，沿路寻找前人的日记。
  2. 按日记的线索，分别在实验楼二楼、四楼、五楼的教师台找到图纸；三张拼好后回到物理实验室的基座。
  3. 铜线圈：校长办公室翻出机房钥匙 → 网络中心，交互服务器。
  4. 透镜：物理实验室的显微镜。荧光试剂：二楼化学实验室的离心机，甩成功的那一次（失败了等冷却再试；带着护目镜更容易成功）。
  5. 电池：课桌、实验室、售货机都能翻到。
  6. 四样都在身上，回物理实验室的实验台组装，走进光圈。

三样实验材料丢了可以回原处再拿；组装后暂时离开，回实验台还能再进光圈。

10 / SETTINGS

画质与设置

主菜单可以选画质、调亮度；暂停后的「设置」里还有音量、字幕停留时间、画质、镜头晃动、音乐 / 环境声、画面颗粒（觉得画面太「沙」可以关掉）。关掉镜头晃动后，状态卡在理智很低时也不会跟着抖。觉得画面太暗就调高亮度——这所学校本来就很暗：灯管老了，有的已经坏了，夜里不开手电只能看见轮廓。

画质内容
流畅最简的一档模型、没有草、低分辨率（材质贴图 256 像素）；手机第一次打开默认这一档。
均衡中等精细的模型（课桌椅、床、柜子、门窗、楼梯、车……）、512 像素的材质贴图和浮雕（砖缝、地砖缝、木纹、吊顶的针孔这些侧光下有起伏）、窗口透进来的光柱、草地。
精细模型同均衡；实时阴影、更细的树冠、更密的草、楼外立面细节。
超精细更细一档的模型（倒角、螺丝、书页、脚轮）；高分辨率、1024 像素的材质贴图、抗锯齿、更细的阴影、顶灯投影、环境光遮蔽，更平滑的人物和曲面。
真实最细的一档模型；没有棱角：所有方块都是圆角，圆柱、杆全部平滑；物理材质和环境反射、灯光辉光、更强的遮蔽；音效按所在空间（教室、走廊、车库、钟楼、宿舍、室外）改变回声，有方位的声音戴耳机能听出方向。需要较强的显卡。

五档画质的玩法、障碍和碰撞完全一样，切换时保留当前进度、追逐和异象。换到另一档时，那一档的模型（以及超精细、真实用的高清材质贴图）在后台载入，载好后自动换上。持续卡顿时会出现「降低一档」的提示，由你决定是否降档。

11 / HELP

常见问题

视角不动或鼠标不见了？

先关掉背包、地图、选项和暂停菜单。电脑上点一下画面重新锁定鼠标，或按住画面拖动；触屏在空白处滑动。切出窗口后游戏会暂停，点「继续」。

为什么拿不到东西？

走近并面朝目标再交互，翻找时站着别动等那一圈走满。再看看背包是不是满了；很多容器本来就是空的，而且只能翻一次。重要物品出现前，最好留一两个空格。

门打不开？

有的门上了锁，提示会写「开门（锁着）」，需要对应的钥匙（多半在校长办公室）。

主菜单提示「模型加载失败」？

模型和贴图在打开页面时按画质载入（流畅档约 2 MB，真实档约 9 MB）。网络断了，或者本地文件没下全（缺 game3d/assets/ 里的包），就会停在主菜单显示这条提示，检查后点「重试」。游戏里换画质时载入失败，会继续用原来的画质。

如何在本地游玩？

游戏和 Wiki 都是仓库里的本地文件，不需要联网。下载完整仓库后直接打开 index.html，或在仓库目录运行 python -m http.server 8000 后访问 http://localhost:8000/。源码、更新说明和问题反馈见 GitHub 仓库。

本指南依据仓库当前的 3D 版代码整理；游戏更新后，以游戏内的实际提示为准。
