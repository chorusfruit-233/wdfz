# 武大附中 · 里世界 3D

3D 校园怪谈探索游戏。仓库首页 `index.html` 是游戏入口，原来的 `3d.html` 链接会自动跳转到首页。

[开始游戏](https://chorusfruit-233.github.io/wdfz/) · [游戏 Wiki](https://chorusfruit-233.github.io/wdfz/wiki/)

Wiki 收录操作、课表、地点、道具、异象和四条结局攻略；异象详解与结局路线默认折叠，方便避开剧透。游戏主菜单也可以打开 Wiki。

本地运行时，在仓库目录执行 `python -m http.server 8000`，然后访问 `http://localhost:8000/`。游戏所需的脚本和素材均在仓库内。

桌面端使用 WASD 移动、鼠标环视、Shift 奔跑、E 交互；Tab 打开背包，Esc 关闭面板或暂停。触屏设备使用左侧摇杆移动，滑动屏幕转动视角。页面右上角可切换全屏。

开发与画面更新见 [3D 更新说明](3D更新说明.md)，操作回归检查见 [tests/README.md](tests/README.md)。
