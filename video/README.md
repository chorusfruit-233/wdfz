# 宣传片（第二版）

`trailer.mp4`：《武大附中 · 里世界》宣传片，约 93 秒，1280×720，24 帧，H.264 + AAC。2026-11-01 从零重做；第一版（2026-10-28）存档在 [`v1/`](v1/README.md)。

画面全部是游戏本身实时渲染出来的——同一套场景、建模、灯光、异象和死亡演出，只是镜头由脚本摆；配乐和音效全部用代码合成，没有任何外部素材。只拍玩家 Wiki 上公开的内容，不出现任何钟点。

## 结构：同一个机位，拍三天

| 段落 | 镜头 |
| --- | --- |
| 第一天（白天，一切正常） | 「第一天」→ 北门往里推 → 高二（六）班，从你的座位看黑板，同学都在 → 教学楼一楼走廊 → 四楼窗台上站着一只白色的杯子（画着二校门，淡紫色的盖子）。 |
| 第二天（黄昏，同样的机位） | 「第二天」→ 北门：门里的路中间站着一个人，最后一下它已经贴在门上 → 同一个座位：全班回过头，墙上一只只睁开眼睛 → 同一条走廊：灯两短一长地闪，尽头站着一个人 → 同一个窗台：杯子在晃，掉下来，砸在面前，盖子滚开。 |
| 第三天（夜里） | 「第三天」闪了两下，变回「第一天」→ 下不完的雨 → 蛾群 → 钟敲十三下 → 地下车库：手电照过去，车之间站着它 → 巡察者：灯一下子全红，它从走廊那头走过来 → 躲进柜子，从门缝看它走过去。 |
| 规则与出路 | 「规则只有一条：活过今天。」→ 讲台上那张钥匙移交单 → 开车冲出去（车库点火、冲出北门）→ 让闸机认出你（红灯变白）→ 或者，造一扇门（光圈）。 |
| 结尾 | 四种死法闪切（跟上来的人群、笑、杯子、地下伸出的手）→ 片名「武大附中 · 里世界」/「每一天，都和昨天一样。」→ 回到第一天的教室，耳边有人问：「……你作业交了吗？」 |

画面上的字（「第一天」的红章、地点卡、「异象」小章、字幕）用的是游戏界面同一套颜色：纸色字、公章红、细线。

## 配乐

`score.py` 用 numpy 合成，时间轴直接读 `storyboard.json`：

- **第一天**：学校报时铃（四音一组）、八音盒旋律（C 大调）、暖的和弦，教室里翻书、粉笔的小动静。
- **第二天**：同一段铃声和旋律放慢、往下走调、换成小调；低频的小二度持续音进来；全班回头时一群人「啊——」，走廊的灯管两短一长，杯子下落的哨音和落地的「当」，盖子滚开。
- **第三天**：「第三天」的铃声卡住、一截截重复，又从头响起——是第一天的铃。之后低频持续音压满，每个异象一声刺耳的切镜和它自己的声音：雨和雷、扑翅、越敲越走调的钟、车库滴水、越来越近的脚步和心跳、柜子里闷住的呼吸。
- **规则与出路**：一个越来越快的低音脉冲；打火和发动机、闸机两声「嘀」、往上滑的光圈。
- **结尾**：死法闪切各一声；片名前一片寂静，然后一声巨响和钟、八音盒最后几个音；尾声回到第一天的和弦，一句贴着耳朵的气声，最后和画面一起一刀切掉。

## 文件

| 文件 | 作用 |
| --- | --- |
| `storyboard.json` | 镜头表：顺序、时长、画面上的字。改时长画面和配乐一起跟着变。 |
| `shots.js` | 每个镜头怎么搭场景、摆镜头、推特效（只在渲染时注入页面，游戏本身不加载）。 |
| `render.py` | 逐帧渲染到 `video/build/frames/`。固定步长，不受实时帧率影响；每个镜头开始时固定随机种子并重新搭场景，所以可以按镜头分给几个浏览器并行渲染，结果一样。 |
| `score.py` | 生成 `video/build/score.wav`（约 10 秒）。 |
| `build.sh` | 上面两步 + ffmpeg 压成 `trailer.mp4`。`video/build/` 是中间文件，不提交。 |
| `v1/` | 第一版宣传片和它的脚本（存档，路径已改好，仍可单独重做）。 |

## 重新生成

需要 Python 3、Playwright（Chromium）、numpy、ffmpeg（libx264）。在仓库根目录：

```bash
CHROMIUM_EXECUTABLE=/path/to/chromium JOBS=2 bash video/build.sh
```

- 软件渲染（SwiftShader）约 1 秒一帧，整片约 2200 帧；四核机器上 `JOBS=2` 大约 25 分钟。
- 预览：`python video/render.py --only d2cup,deaths --step 6`（只渲染这几个镜头，每 6 帧截一张）；`--sparse` 只推进要截图的帧，粗看构图更快，但闪电、雨、闪光这类逐帧累积的效果会不准。
- `--out` 必须是新建或空目录，避免覆盖已有文件。
