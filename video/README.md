# 宣传片

`trailer.mp4`：《武大附中 · 里世界》宣传片，约 99 秒，1280×720，24 帧，H.264 + AAC。

画面全部是游戏本身实时渲染出来的（同一套场景、灯光、异象特效，只是镜头由脚本摆）；配乐和音效全部用代码合成，没有任何外部素材。

## 结构

| 段落 | 内容 |
| --- | --- |
| 开场 | 黑场。「每一天，都和昨天一样。」一声钟，八音盒。 |
| 建筑 | 北门（雾里往门口推）→ 教学楼（从一楼仰到楼顶）→ 高二（六）班（坐满的背影，中间空着一个座位）→ 一楼走廊（灯两短一长地闪，尽头站着一个人）→ 钟楼（门口仰看旋转楼梯）→ 地下车库（手电照过去，车之间站着那个人）。 |
| 异象 | 「然后，异象开始了。」下不完的雨（闪电和雷）→ 蛾群 → 全体回头（墙上一只只睁开的眼睛）→ 清华水杯（四楼窗台上晃，掉下来正对镜头）→ 巡察者（灯一下子全红，它从走廊尽头走过来）。 |
| 玩法 | 「规则只有一条：活过今天。」躲进柜子（门缝外它走过去）→ 找齐四样东西造一扇门 → 或者开车冲出北门。 |
| 收尾 | 心跳越来越快的闪切 → 片名「武大附中 · 里世界」→ 黑场里一句「……你作业交了吗？」 |

## 配乐

`score.py` 用 numpy 现场合成，按 `timeline.json` 的镜头时长对齐：

- 底层：36.7 Hz 和 38.9 Hz 的小二度持续音互相拍出颤动，按段落起伏；异象段叠一层高音小二度簇。
- 八音盒动机（开场、教学楼、片名各出现一次，最后落在不稳的音上）。
- 铜钟：非整数倍泛音；钟楼的第三下故意走了调。
- 每个场景、每个异象都有自己的声音：走廊脚步与灯管电流声、车库滴水、雨声与雷、蛾群扑翅、全体回头的人声「啊——」、水杯的叮当—哨音—「当」、巡察者越来越近的脚步和心跳、柜子里闷住的呼吸。
- 每次切进异象都有一声刺耳的切镜（低频冲击 + 高音小二度锯齿）；结尾闪切的心跳从每分钟 130 拍一路加速。
- 混响用一段衰减噪声做冲激响应，左右声道去相关。

## 重新生成

需要 Python 3、Playwright（Chromium）、numpy、ffmpeg（libx264）。在仓库根目录：

```bash
CHROMIUM_EXECUTABLE=/path/to/chromium bash video/build.sh
```

- `timeline.json`：镜头顺序、时长、字幕。改时长后画面和配乐会一起跟着变。
- `trailer.js`：每个镜头怎么搭场景、怎么摆镜头（只在渲染时注入页面，游戏本身不加载）。
- `render.py`：逐帧渲染到 `video/build/frames/`（固定步长，不受实时帧率影响；软件渲染约 0.8 秒一帧，整片约半小时）。`--only <镜头>` 只渲染一个镜头，`--step N` 每 N 帧截一张做预览。
- `score.py`：生成 `video/build/score.wav`（约 10 秒）。
- `build.sh`：上面三步 + 用 ffmpeg 压成 `trailer.mp4`。`video/build/` 是中间文件，不提交。
