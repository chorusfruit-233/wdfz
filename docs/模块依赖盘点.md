## 5. 键盘输入优先级（`KEY_ROUTES`，从上到下）

| 顺序 | 上下文 | 说明 |
| --- | --- | --- |
| 1 | `dev-toggle` | F2：打开 / 关闭调试面板 |
| 2 | `free-cursor` | Alt / `：放出或收回鼠标（游戏不暂停） |
| 3 | `dev-panel` | 焦点在调试面板里：Tab 留在面板内，Esc 关闭 |
| 4 | `dev-freeze` | 调试冻结时：Esc 关闭面板 |
| 5 | `editing` | 输入框里打字；Esc 离开输入框后继续往下分派 |

| 7 | `prologue` | 文字前情提要：空格 / 回车翻页 |
| 8 | `death-skip` | 死亡演出：空格 / 回车 / Esc 跳过 |
| 9 | `not-playing` | 不在游玩中，或按着 Ctrl / ⌘ / Alt：不接 |
| 10 | `escape` | Esc：依次关电脑、手机、课堂、设置、手册，最后暂停 / 继续 |
| 11 | `button-space` | 焦点在按钮上：空格交给按钮自己 |
| 12 | `pc` | 机房电脑小游戏：方向键 |
| 13 | `lesson` | 课堂短任务：1–3 选答案 |

| 15 | `choice` | 选择框：数字键直接选 |

| 17 | `car` | 驾驶逃脱：方向键 |
| 18 | `journal` | Tab / H / J / M：手册的背包、思索、笔记、地图 |
