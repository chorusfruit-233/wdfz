## 3. 第二阶段 P1：五分钟恐怖体验切片

**建议场景**：教学楼一段正常教室 → 灯光略有异样的走廊 → L 型转角与储物柜 → 需要短暂停留的搜索点 → 有机会选择观察或撤离的异常区域。

- [ ] **0:00–1:00 安静与目标**：正常校园底噪、脚步与门声，明确探索目的，不立刻刷怪。
- [ ] **1:00–2:00 先听后见**：远处广播失真、脚步方向变化、门轴声；至少一处线索可能只是环境噪音，不保证立即有怪物。
- [ ] **2:00–3:15 危险操作**：搜索柜子／打开门的停留时间和可能的风险，提供观察、躲藏、等待或撤离选择；触屏响应保持可靠。
- [ ] **3:15–4:15 威胁兑现或落空**：利用现有巡察者／普通异象调度，控制同场叠加，允许可理解的追逐脱离；不要擅自改变固定剧情或隐藏时刻。
- [ ] **4:15–5:00 喘息与余韵**：短暂安静、环境痕迹或可选线索，测试玩家是否愿意继续探索而非只想退出。
- [ ] 使用现有几何与资源完成灰盒测试；测试后才决定是否需要新模型、额外灯光或音效素材。

**验收**：玩家能描述危险来自哪里、做过什么选择；至少出现一次可解释的犹豫／观察行为；没有必须靠读档背答案的设计。

## 4. 第三阶段 P1：音效与空间异化

- [ ] 检查脚步材质、空间混响、墙体遮挡、远近定位、广播方向、门／柜／楼梯／电梯声音；建立「声源—传播—玩家判断—实际后果」表。
- [ ] 给普通教室、走廊、厕所和实验楼设计少量可回访的变化：灯光、黑板文字、物件位置、脚步回声；先用现有系统组合，禁止无依据叠加更多致死异象。
- [ ] 校验正常供电／停电与正常世界／假正常的视听差异；黑暗中仍能辨认可走路线与交互，字幕不被强烈滤镜遮盖。
- [ ] 对 Jump Scare 设置区域预算和冷却，记录前兆、强度与恢复间隔；把无害／假威胁作为节奏手段而非反复欺骗玩家的套路。

**验收**：闭眼听声可大致判断方向／远近；静音仍能理解重要风险；低画质下空间逻辑不变；同区域连续强制惊吓显著减少。

## 5. 第四阶段 P2：AI 导演与动态重试（仅可行性评估）

- [ ] 先统计异象调度、巡察者感知与现有冷却；提出可选的宏观张力预算，明确不影响课表、已确认的定时检查、剧情节点和隐藏触发规则。
- [ ] 对噪声吸引、搜索记忆、巡察者丢失目标后的行为做小规模试验，保留视线／遮挡与可逃脱性；不要先做全新大型 AI 架构。
- [ ] 统计同处连续死亡 2–3 次的原因；优先增加可读线索、缩短无意义重走和修复碰撞，动态调整只改变非关键遭遇的路径或表现，不随机修改核心规则。
- [ ] 比较有无导演系统时的追逐成功率、死亡归因、等待时长与挫败感，确认有收益才进入正式开发。

**验收**：不出现新软锁、随机必死、固定剧情被打乱或存档重抽作弊；若没有明显体验收益，保留现有调度。
