# 规则怪谈、纸飞机与窗内视线

> 独立计划初稿 v0.1，2026-11-04，依据 `main@b60c763`。用户已明确要求将本计划直接合入 main；合入范围为计划正文与目录。玩法、模型、CG 均未实施。具体视觉与 CG 由 Claude 接续制作计划、实现并优化审核；本文分镜是供其接续的设计草案。
> 用户要求：10% 遭遇的窗口纸飞机；默认关闭、面板可开的全游戏规则怪谈 Mod，包含真、假、半真半假规则及不同载体；不可直视且难脱离的窗内视线；需要快速阅读、投回并操控纸飞机避墙的“飞纸飞机的人”，普通模式纸上改为提示；完整死亡 CG、成就及恐怖体验优化。
> 本文含内部规则答案与死亡条件，不直接复制到玩家 Wiki。实施前复核最新 main、开放 PR 与相关计划。原始提案中的参数标为建议，等待定稿。

## 1. 核心体验与功能划分

纸从一扇真实窗口飞出来，贴近玩家后落地。玩家从纸、公告、课表和物品批注中学习校园规则，但每份文字的可信度都需要证据。最初是读一句话，后来发现窗后有人等着回复；把纸折回去以后，玩家要亲自操控它穿过走廊，送回那扇窗。

| 内容 | 普通模式（默认） | 规则怪谈 Mod 开启 |
| --- | --- | --- |
| 平和纸飞机投递 | 10% 遭遇系统中的一类，携带环境／路线提示；可拾取留存 | 同样的实体投递，可携带规则或规则残片 |
| 飞纸飞机的人 | 危险投递：提示说明来意与返航操作，快速读完、投回、操控飞行 | 危险投递：纸上是带真伪信息的规则；阅读、辨别关键要求、投回和飞行仍是完整流程 |
| 窗户内的视线 | 可独立发生的致命异象，直视持续掉 SAN，并产生难以转开的视线牵引 | 同一物理危险；纸条、贴纸等可提前提供真假不一的应对说明 |
| 全游戏规则系统 | 无规则判定覆盖，使用既有玩法和新异象的明确提示 | 在既有玩法上增加有版本、作用域和证据链的规则层；覆盖全校多个系统 |

平和投递与危险投递必须可辨认，不能把所有纸条都改成隐藏死亡倒计时。没有拾纸的玩家也应先听见拍窗或看见等待者等前兆，再进入危险阶段。正常版的新玩法同样有读纸、投回、避墙和死亡，不因关闭 Mod 而省掉返航模拟。

## 2. 当前代码和需要补齐的接口

- `game3d/mods/index.js` 已有默认关闭的自带 Mod 登记；暂停菜单有“Mod 与模块”，调试面板有“Mod”页，开关通常刷新后生效。沿用此入口，增加清楚的模式状态和新局配置，不要求玩家先开调试。
- `anomaly.js` 管异象、`dread.js` 管非伤害氛围和惊吓预算。当前弱惊吓至少间隔 9 运行秒、同区 24 秒，强惊吓 45 秒／同区 120 秒；新危险由独立玩法状态推进，氛围层只读，不从表现层扣 SAN 或判死。
- 现有 `fx/gaze.js` 是会穿墙显示的装饰眼睛，不能直接用作窗内视线的可见性判据。新事件必须绑定实际窗口、楼层和遮挡，渲染与碰撞使用同一空间变换。
- 背包当前 8 格；新纸片需要落地、阅读、折叠、投出、回收与失效状态，不能只加一个“使用→成功”的按钮。主角输入／纸飞机输入／阅读面板须有明确归属。
- 现有成就对用户 Mod 局有可信限制：`modules/achievements/achievements.js` 会将启用非 `source:'code'` Mod 的本局标为 Mod 局。规则怪谈作为自带 Mod 不能假装普通局解锁全部本体成就，方案见第 11 节。
- 最新 main 已接 WebGPU／WebGL 回退；后续所有窗口材质、纸片文字、相机、拖尾和死亡舞台都需要双后端验收。开放走廊／教学楼重修、电梯和恐怖氛围等在途 PR 的布局须先同步。

## 3. 10% 的抽取口径与纸飞机投递

### 3.1 建议默认：一局一次“纸飞机遭遇资格”

用户只指定“只有 10% 概率遇到”，未指定每分钟／窗口／每天。首版建议**每局只抽一次 10% 总资格**，两个模式一致，读档不重抽；未命中本局不生成这两类纸飞机。命中后在首个条件合法的窗口机会兑现一次完整投递事件，不能每路过一扇窗抽 10% 导致几乎必遇。与其他稀有事件使用独立玩法随机状态。

平和／危险是同一次资格中的事件种类，不能各抽一个 10% 让总概率变为 19%。建议首版各半：全局约 5% 平和、5% 危险；这个子类比例未经用户指定，列入第 14 节确认。若后续改为每天 10%，必须同时改说明、冷却和测试，不能悄悄扩大抽取次数。

兑现条件：真实可打开／有开口的窗口，有合法起飞点、玩家附近可落地处和可返航路径；主角没有正在进行的追逐、检查、驾驶、电梯、结局、死亡、梦境或强制选项。资格命中但当前不可放行时排队，保留抽取结果，不强行打断已有危险，也不让缓存预览窗口触发。

### 3.2 入场与落地

纸飞机从物理窗口出发，沿可碰撞的飘落轨迹到玩家 1–2 m 范围内，绕开身体和栏杆后落在合法地面。玩家突然移动时只更新可达落点，不追踪贴脸、不穿玻璃、不飞过楼板；不可达则退回等待，不扣一次资格。落点失败不得把纸塞进满背包。

“地上有纸”的存在是权威对象，有稳定 `paperId` 和表面 ID。可见实体与可拾取实体同源；楼梯半层、走廊和连廊接缝不会把纸掉到楼下。被玩家看见的投递不能用提前生成的静态纸片冒充全过程。

平和投递：轻薄纸、一次小小擦地声，落下后普通留存，无致命期限。危险投递：折痕压得异常整齐，窗口有等候者，一次明显的双拍窗声；没有颜色专属判别，静音也能看懂等待和催促。两类外观线索可相似，但危险总有额外可感知前兆。

## 4. 全游戏规则怪谈 Mod

### 4.1 入口、默认值与存档

自带 Mod ID 建议 `campus-rules`，默认关闭，在**暂停菜单“Mod 与模块”→“自带玩法”**选择。菜单说明只写“校园内可发现相互矛盾的文字，部分会影响行动”，不直接提供答案。新局确认页显示是否启用；选中后按既有加载流程刷新再开始新局。调试页为测试入口，不是唯一开关。

本局规则模式和规则集版本写入存档。中途改面板的开关只影响下一新局，不能靠关闭 Mod 躲过当前索命期限；恢复存档时提示它需要的模式，按存档原模式继续，或退回菜单。`?nomod` 排障时保留原数据并禁止继续覆盖这一规则存档，提供使用独立普通槽新开局；不能借排障免费清除危险。旧普通存档按关闭处理，绝不自动转换。

### 4.2 真／假／半真规则的数据定义

规则对象至少有 `id, version, scope, condition, actualOutcome, textVariants, carrier, evidence, expires`；文本是角色在世界中写下的说法，实际判定有单独权威定义。每局规则稳定，不能因为玩家读过又随机翻真假。真伪不靠“纸新／纸旧”“墨黑／墨红”一眼判定。

- **真规则**：在给定范围与条件内，文字与机制一致。不是全游戏永久有效，例如“第二遍拍窗之后，请把折好的纸从来处送回”。
- **假规则**：文字的保护承诺不成立，或要求会引向已有危险的动作；必须有可发现的反证。假规则是叙事内容，不是临时改变碰撞、随机取消正确行为或事后改判。
- **半真半假**：拆成可独立验证的子句，例如前半句告诉玩家低头可以避开目光，后半句却诱导抬头确认它走了。系统记录验证的是哪一条子句，不用一个模糊布尔值评“玩家是否遵守”。

不在 UI 给真／假颜色标签。玩家能记录原文、出处、相互矛盾的证据与自己的“可信／存疑”标记；记录不自动验真。原文和必要图片可重复查看，不迫使记住小字号全文。

首批每局从经过相容性校验的规则组选择，不独立乱抽所有规则；至少包含三个真、两个假、两个半真样本并有可走路线取得证据。规则不能要求玩家同时抬头和低头、准时检查又守在远处；受强制流程占用时相应规则期限挂起或不启动。解决冲突的优先级需在设计数据中声明，不靠文本“最终解释权”。

## 5. 恐怖异象：窗户内的视线

### 5.1 触发与持续 SAN 流失

建议 ID `window_gaze`。在本来可以看进房间的真实窗格内出现一双非常安静的眼睛，背景人物不动，玻璃倒影晚半拍；不能把开放走廊栏杆当窗，也不从背面／隔不透明墙吸住玩家。

依视线夹角、距离、实际遮挡与暴露时间判定：建议正视半角 12°、距离 2–18 m、持续接触 0.35 运行秒后开始牵引与 SAN 流失。SAN 消耗建议初始 2／运行秒，连续正视 2 秒后升至 4／秒，跨离视线即停止伤害；再盯需重新累计。数值供试玩，不宣称已经平衡；最低 SAN 也要有反应余地，不在前兆阶段直接秒杀。

SAN 到 0 且本次有效目光造成耗尽时，死因归 `window_gaze`，进入专属 CG；其他来源先耗尽则尊重原来源。药丸／免疫沿既有保命链处理，成功后立即解除目光并给合法身体／镜头方向和短安全窗口，不在同一帧再次吸回去。

### 5.2 “很难脱离”的可操作设计

牵引是限幅的视角吸附，不锁死所有输入。转离窗口时阻尼加重，中心焦点像被线拉住；玩家持续向外拖视角能克服牵引，同时可低头、侧后退到窗框／柱子遮挡。建议低头超过 35°或离目标方向超过 28°持续 0.6 秒即断开；真实不透明遮挡立即断开，不要求先等动画结束。

视角控制属于带来源的应用层控制，只有这一效果生效；表现相机只读结果，不能 `lookAt` 每帧覆盖鼠标。屏幕晃动关闭后仍保留玩法吸附与可见拉扯提示，减少呼吸形变而不削弱脱离能力。键鼠和触屏在同样输入时长内都能挣脱，不能要求手机甩动设备。按暂停正常冻结并释放指针，不把暂停键当反复刷新免伤的技能。

不禁止抬手读纸来当硬性解法；若此时读纸遮住窗口，视线应按真实遮挡／视角判断。危险纸飞机阅读阶段不同时新开目光，返航控制阶段也不把主角锁进另一个看不见的致命牵引。

## 6. 异常：飞纸飞机的人

建议 ID `paper_sender`。窗口后有一只手，纸落地后没有立刻收回；等玩家捡起才开始屈指计数。随后手消失，脚步却从楼梯方向接近。它沿实际空间来，不能在超时那一帧无声瞬移到脸上。

### 6.1 阅读和返还期限（建议值）

- 到达玩家身边后先留 **8 运行秒**拾取前兆，拍窗两次。对没有看到纸的玩家只启动催促阶段，不从纸穿过窗的那帧暗扣阅读秒数；长时间拒收也进入逼近，不能永久拖住事件。
- 拾取／首次展开时进入 **8 运行秒阅读阶段**，纸上至多 2–3 条短句、约 45–65 个汉字。阅读面板自动对焦到文字，缩放和文字等价转录可用；选择“折好投回”后进入投出准备，无强制自动折叠。阅读期限不因把纸关了再开而重置。
- 投出准备 **4 运行秒**，标明对应的实体窗口／窗号，玩家自行对准开口投出。关键操作说明始终直白：操控方向、避墙、目标窗，绝不把键位藏在假规则里。
- 飞行时限按可达长度计算 `L / 标准速度 + 容错余量`，建议通常 **12–20 运行秒**。前两段独立计时，不能因为读得快凭空多出一条更短路线；成功必须到原窗口接收面。

使用有时钟域的阶段状态，读纸／投出／飞行推进有效运行秒；普通背包面板不暂停期限，真正暂停、失焦冻结整个相关模拟与期限。大字号／转录模式按实际排版可读长度校准，不给视觉障碍者同一页更多行却更短时间；必要时用等价精简文本，所有信息同等齐全。

普通模式纸上示例：“他还在那扇窗后等。读完就折好，别留在手里。送回有缺角的窗，转弯别碰墙。”规则模式示例：“两次拍窗以后，纸从哪里来就回哪里去。返程不能碰墙。若字看不清，贴近玻璃再念一次。”前两句为真，末句可为假；窗口本有一条低位反证“别走近玻璃”。读完不由眼动追踪判定：玩家主动选择折回就是完成阅读动作，是否理解用之后行为体现。

### 6.2 失败和死亡流程

超出阶段期限、将纸丢弃／撕毁、投向错误窗口、飞机撞墙／地板／栏杆或飞行严重越界：本次返还失败，转为“找上来”。失败只提交一次并指明发生了什么；先有可听脚步、门把动作、墙上影子或字幕提示，再沿预先验证可达的路径逼近。

草案失败后留 **3–5 运行秒**兑现威胁，再由 `paper_sender` 专属死亡链处理；不把它标为“已安全”也不悄悄减 SAN 冒充处理。是否允许失败后通过临时藏身点挽救，用户未指定，首版建议失败不可重投，按有前兆的致命后果设计并列入确认。若未来允许补救，必须有独立且能解释的规则。

来客实际路径长于这段时间时，按可达路径长度延长逼近，不提速穿墙或瞬移补齐时限；生成前同时验证玩家投出点与来客到达路线。已有其他来源先提交致命结果时取消本事件，不在第一次死亡／保护之后再补一次过期抓取。

已有药丸／免疫可以按既有机制挡一次死亡。挡下后事件清理、纸失效、恢复原输入，保留其他来源的巡察责任；不产生无限连抓。停止读纸／自动关闭面板不等于逃脱；但主动退出游戏后读档也不会被按离线时间判死。

## 7. 纸飞机模拟飞行

### 7.1 视角和输入

玩家投出后，镜头跟到纸飞机后方，保留窗口目标与附近墙体；先展示一次不计时的通用操作教程（新局开始／首次安全练习区），正式返航不临时弹半屏教程。飞机运动是持续滑翔，不是点击路线后自动完成。

键鼠建议方向键／WASD 控横滚与俯仰，触屏一个独立操纵区，偏转可回中；默认正向操纵，反转俯仰单独设置。机身有速度、升力、阻力与有上限的风偏，俯冲可换速度、抬头会掉速；首版用可调的简化飞行动力学，不承诺真实航空模拟，也不做必须精确配平的高门槛控制。建议巡航 3–5 m/s、横滚不超过 35°、俯仰不超过 20°，低帧率不改变航迹。

主角身体停在真实投出点，不在飞行中瞬移。启动前验证投出位置对该玩法有足够安全性；不会在已经被巡察贴身抓住时强制转镜。飞行期间纸飞机优先占用操控，暂停／退出菜单仍可靠；不同时用 WASD 移动主角或滚屏。可在小角标看到自己的位置和听见现场脚步，避免切镜后完全失去世界状态。

### 7.2 碰撞、到达与路线公平

以小型有向碰撞体扫掠机头／翼尖，步长独立于渲染帧；墙、玻璃、栏杆、门扇、楼板、立柱、动态人物均按同一世界高度判断。擦过空气孔隙可通过，碰到实体杆件才算撞；低画质不能少算栏杆，也不能用整块不可见矩形封掉可见空隙。

目标窗口必须开放，设置实际入口平面和接收范围。正确方向穿过接收面、身体／翼尖有净空才算到达；靠近窗外或撞上玻璃都不成功。投递来路和返航路线可不完全重合，但两者都真实可行。每次事件先验证路线长度、转弯半径、时间预算与可达性；未通过则延后／换窗口，不让玩家承担生成失败。

风场在事件开始时锁定版本和种子，提前有窗帘／纸角提示。默认没有无提示突变强风；难度增加以可读转角和有限风偏为主。返航可以跨连廊或绕立柱，首版只接一处经验证走廊／窗外短回路，再扩场景；不飞到未加载校园空洞。

成功：窗口的手接住纸，纸从玩家背包和世界里同一事务移走；回主角镜头，解除危险并记录归还事实。失败：保留碰撞点与机体停下的短镜头，再回主角视角进入逼近；两种收尾都清除飞机输入、相机、声音和缓存。返航不是传送捷径，禁止携带玩家或把纸当越墙拾取工具。

## 8. 恐怖体验优化：让玩家能推理、能行动

1. **先让窗可信，再让窗异常**：几次经过看到正常空房间，下一次同机位只有帘子内侧出现呼吸。不要每个窗口都放眼睛，纸飞机与视线的窗口身份记录下来，回访变化有来源。
2. **不完整信息带来选择**：纸条首段是真规则，尾端像另一个人补写；用压痕、时间戳和可观察的行动结果让玩家形成假设。辨别的成本是时间和路线，不能每次试错都要求先死一遍。
3. **声音先行**：飞机擦过窗框、远处屈指拍玻璃、纸展开的轻响，先于人影。声源带世界位置和遮挡；声音字幕传达“窗后／走廊尽头”等有证据的信息，静音玩家也能应对。
4. **身体被吸住的压力**：窗内目光由眼睛跟随、转头阻尼和呼吸变浅表现，牵引时仍有可成功的脱离方法。避免高频闪烁、乱转相机或把文字扭曲到无法读完。
5. **读字时出现安静的变化**：纸页近景在前，背景门把轻轻转一下；文字不会在读完前乱跳或缩小。读完后再检查前后差异，给“我是不是漏了一句”的记忆压力。
6. **返航让紧张可控**：练习很短，正式路线熟悉但视角变低；纸在翼尖离墙几十厘米时发出摩擦前兆，成功窗口有固定可识别形状。玩家失误可归因，不用随机失速骗死。
7. **兑现后留白**：归还成功后 15–25 运行秒不派新强威胁，窗后手缩回，玻璃上留一块没有掌纹的雾；已有独立危险不清除。让喘息成为下一次紧张的参照。
8. **记录后果，少弹说明**：笔记记实际见到的文字和结果，不告诉玩家“你违反了假规则”。死亡界面提供对应失败来源和一句回忆，下一局能改策略；精确条件留内部。
9. **五分钟切片**：安静走廊约 45 秒→低风险读一条真规则→窗内呼吸、试着脱离→纸落地→阅读和返航→成功的空窗／失败的脚步→余韵。测试切片固定事件种子，不能声称验证了自然 10% 出现率。
