# 游戏音效重做

> 2026-11-02 用户要求「重置所有游戏音效」，随后补充「上下课你也记得改」。本计划在 [PR #27](https://github.com/chorusfruit-233/wdfz/pull/27)（基于 PR #26）实施，同一 PR 还有虚空迷宫的新结构（见[虚空迷宫、粉笔记号与模块化](虚空迷宫、粉笔记号与模块化.md)第 10 节）。
> 部分音效属于内部彩蛋（异空间），本文只写内部开发需要的信息；玩家 Wiki 只写上下课铃的区别和「音效现场合成、每次略有不同」这类公开信息。

## 1. 目标与范围

- **全部一次性音效重做**：界面、脚步、开门、楼梯、拾取、铃、雷、异象开头、远处的假威胁、心跳、死亡、演出、环境点缀（虫鸣、滴水、灯管、蛾子……）、钢琴与八音盒、异空间里的零星声音，一共 128 个，全部改成配方，由同一个播放器现场合成。
- **上下课铃**：原来上课、下课是同一段方波「嘀嘀」。改成两种能听出来的铃——进入上课时段是一阵急促的电铃，离开课堂时段是一段四个音的钟声；室外更远、更闷。玩家光听铃声就知道该不该回教室（课表与违规是核心循环的一部分）。
- **不改的**：持续的环境层（BGM 铺底、风、雨、灯管嗡声、车库低频）保留原合成，只接到新的分类总线上；所有调用名（`SFX.click / door / step / dread / deathFx / anomaly …`）不变，游戏逻辑一行没改；惊吓预算、骤静、前兆的调度不变。
- 不加载任何音频文件，离线、`file://` 照样可玩。

## 2. 设计

| 层 | 文件 | 说明 |
| --- | --- | --- |
| 声音库 | `game3d/js/sound-bank.js` | 只有数据：`SOUND_CATS`（11 个类别和响度目标）、`SOUND_BANK`（128 个配方）。配方由层组成：`tone` 振荡器（滑音、颤音）、`noise` 滤波噪声（扫频）、`bell` 钟的泛音组、`vowel` 共振峰人声（浊音 / 气声）、`fm` 金属声；层可以重复、振幅调制、单独加混响或声像，整段也能重复。数值写 `[最小, 最大]` 时每次播放重新取 |
| 播放器 | `game3d/js/fx/sound-player.js` | `SoundPlayer.play / stop / length / measure / validate / add`。同一份代码往游戏混音里放（分类总线 → 主音量 → 压缩器，带混响和方位），也往离线渲染里放（测响度） |
| 响度校准 | `game3d/js/sound-levels.js`、`tools/sound_levels.py` | 工具在无头 Chromium 里离线渲染每个配方（4 个固定随机种子取平均），量 K 加权的 100 毫秒最大响度，按「类别目标 + 配方的 `lv`」写出校准值和[音效响度表](../音效响度表.md) |
| 接口 | `game3d/js/audio.js` | `SFX` 的各个函数改成「什么时候放、放哪一个、传方位和远近」；新增 `SFX.chalk`、`SFX.deep`、`SFX.stopDeath`（以前调用了却不存在）；`stepSurface` 钩子让模块换脚下材质 |
| 试听 | `game3d/js/modules/sound-board/` | 调试面板「工具」页「声音试听」：按类别挑音效试听、整类连放，显示校准值和时长 |

响度目标（K 加权 100 毫秒最大值，dBFS，干声）以旧音效各类的实测中位数为参照，保持原来的整体平衡：界面 −40、脚步 −49、动作与物件 −36、环境点缀 −45、远处 / 假威胁 −46、威胁 −31、异象 / 天气 / 铃 −30、死亡 −26、演出 −32、音乐 −34、异空间 −50。单个音效用 `lv` 相对目标调（例如按钮 −4、钟楼大钟 +6、身后憋着的笑 −20、突脸 +6）。

两处实现要点（测试覆盖）：

- 响度倍率（`k`、随机浮动、校准）放在每个音效出口的增益上，不进包络——包络从 0.0001 起落，峰值一变曲线形状就变，校准会差约 1 dB。
- 增益节点先设成静音再排包络：WebAudio 的增益默认是 1，起音那一刻会漏出一个采样，在游戏里是细小的「咔」（旧代码也有，离线渲染测出单采样尖峰 −0.7 dBFS）。

## 3. 各类声音的做法（摘要）

| 类别 | 做法 |
| --- | --- |
| 脚步 | 鞋跟 + 「嗒」 + 地面闷响 + 前掌落下；瓷砖 / 楼梯 / 车库 / 天台碎石 / 草地 / 跑道 / 球场 / 水泥路 / 异空间白色结构各一套，雨里叠一层踩水；左右脚音高和声像轮流差一点；巡察者的脚步按方位、远近、背后发闷 |
| 动作与物件 | 开门：锁舌「咔」→ 合页「吱——」→ 身后门关上；上下楼一串台阶；粉笔一笔一笔断断续续的「嚓」；水杯、可乐按原来的时间轴重做（金属用 FM） |
| 铃 | 上课铃：1046 Hz 的电铃，锤子每秒二十下，响两秒半；下课铃：C E D G、G D E C 的钟声；钟楼大钟和十三下钟用钟的泛音组 |
| 远处 / 假威胁 | 敲门、走过、拖椅子、低语（气声共振峰）、门被推开、喊、跑过去（声像从一边扫到另一边）、撞课桌、收音机；远处怪声在这几种加上摔门、耳鸣、「啊——」、弹球、轻笑里随机挑，四成隔着楼板发闷 |
| 异象开头 | 每次先一声很低的下沉，再按异象各有一段（停电是继电器一个个跳开、嗡声沉下去；无尽走廊是一模一样、没有任何随机变化的脚步……） |
| 死亡 | 先放共同的下沉和尖鸣，再按 28 种死因各放一段（先听见，再看见），回菜单或退出档案回放时 `SFX.stopDeath()` 淡出 |

## 4. 恐怖设计准入核对

- 声音先行、方向可辨：假威胁和远处怪声保留方位与远近，「真实」档仍用 HRTF；隔墙、背后发闷。
- 不增加惊吓次数：调度、惊吓预算、骤静与前兆逻辑不变，只换声音本身；突脸仍只有原来那一处。
- 无频闪类声音、不刺耳：高频尖音（耳鸣、死亡尖鸣）响度按类别校准，峰值不超过 −1 dBFS；耳鸣 `lv −8`。
- 关掉声音不影响理解：玩法提示仍有字幕、画面和界面；上下课铃只是多一个听觉线索。
