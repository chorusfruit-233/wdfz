## 维护方式

- 新计划存放在 `docs/plan/`，文件名只写正文标题，不添加「计划-」、进度、状态或日期；本文件 `README.md` 是目录索引。
- 新建计划时在本表登记；整体状态变化时更新本表和说明，不为标记状态而重命名文件。计划正文可以记录各阶段进度、历史实施记录和验收证据。
- 按实际交付和验证情况更新状态。历史记录保留当时的代码基线与测试限制，不能因计划整体状态变化而改写为当前测试结果。
- 本目录可能包含隐藏内容的内部剧透；玩家 Wiki 保持彩蛋保密，不复制隐藏路线、触发条件或时刻。
