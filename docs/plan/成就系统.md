## 0. 一页结论

- 共 **56 条**：普通 20、精英 17、史诗 9、隐藏 10。公开的三档 46 条，隐藏 10 条在解锁前完全不出现、不计数。
- **只记录，不加成**：成就不改任何数值、物品、天赋、难度、判定、随机、存档或剧情，也不解锁任何内容（包括皮肤、菜单装饰、档案和提示）。
- 只认**真实游玩**里发生的事实：打开过调试面板的那一局、调试开关开着、档案室回放、演出预览、死亡档案室「全部解锁」都不算；结局要经过正常路线（与速通的 `Speedrun.proof` 同一口径）。
- 跨局记录独立保存（`wdfz3d_achievements_v1`），新局、死亡、通关、档案室「全部解锁」都不会清掉或写入它；本局的进度跟着存档走（`d.mods.achievements`）。
- 事件来源是新增的一个模块钩子 `gameFact`：各系统在**已经发生的事实**处发一次，成就模块只听不改。
- 解锁提示不打断恐怖节奏：异象、追逐、检查、过场、死亡演出期间排队，安全时才显示，并按档位播放不同的短音效（2026-11-03 用户确认要音效）；结局卡和死亡界面汇总本局新达成的成就。
- 本局达成的成就按档位计入另一份计划[积分、评级与通关记录](积分、评级与通关记录.md)的本局积分；积分只是局后评价，成就和积分都不改玩法。

## 1. 目标与硬边界

### 1.1 要做到的

1. 给已有的核心循环（观察课表与校园 → 判断风险 → 搜索 → 躲避 / 冒险 / 逃离 → 承受后果）留下可回看的记录，鼓励理解规则、尝试不同路线和天赋，而不是刷数值。
2. 四档分明：普通记「第一次」，精英要求理解规则并做好一次，史诗是长期目标，隐藏只给真正找到秘密的人。
3. 和死亡档案室、速通、已见结局三套现有记录口径一致，能互相印证，不重复存一份同样的东西。

### 1.2 硬边界（实施和评审时逐条核对）

- **没有任何加成**：不给物品、SAN、体力、时间、天赋、难度修正；不改异象抽取、巡察、检查、结局条件；不解锁任何内容；没有「成就点数」可兑换。成就模块只读事实、只写自己的存储。本局达成的成就会计入局后的积分与评级（另一份计划），那同样只是评价，不回到玩法里。
- **不改现有判定**：不为了成就随机化或改动任何触发条件，尤其是隐藏结局的精确时刻、虚空迷宫入口、隐藏天赋的概率与入口（CLAUDE.md 第 4 节「禁止为了不可预测性随机化隐藏彩蛋的正确触发条件」）。
- **不诱导刷**：不设「死 100 次」「累计跑 50 圈」这类次数刷取；跨局集合都有上限（7、8、10、18、25 种）。不设依赖隐藏数值的条件（SAN、违规、同化在常规 HUD 上不显示，不能让玩家对着看不见的数字刷）。
- **不诱导存读档**：本局类条件的计数跟存档一起保存，读档只会回到那次存档时的计数（保命、西小门答错之后现有代码本来就立即存档，读回也还在）。第二天选了「笑一下」之后目前不会立即存档，实施时评估是否补一次；不为成就改变其余的存档节奏。
- **不打断恐怖**：解锁提示排队、只在安全时出现，音效随提示一起播放（不在紧张段落里响，第 8.2 节）；不进 Jump Scare 预算，不盖住字幕和交互提示。
- **保密**：见第 9 节。隐藏成就在解锁前不出现于成就页 DOM、数量、Wiki 与任何静态文本。

## 5. 可信解锁与无效情形

1. **调试局**：本局一旦打开过调试面板（`Dev.unlock` 成功，收起后依旧算），或者任一调试开关开着（`Dev.modifiersActive()`：快跑、无敌、关掉翻找读条），本局标记 `debug`，之后**这一局不再解锁任何成就**，跨局集合也不计这一局的事实。标记跟存档保存，读档不会洗掉。
2. **调试与演示路径**：`KILL_CTX==='debug'`、调试面板直接触发的异象（`Dev.triggerAnomaly` 绕过 `anStart`）、死亡 / 结局预览、死亡档案室回放（`ArchiveReplay.on`）、宣传片与录制脚本的预览，都不发事实或被模块忽略。
3. **结局要经过正常路线**：结局事实带 `legit = (Speedrun.proofId===id)`，在 `Speedrun.finish` 清掉之前取值；控制台直接调 `triggerEnding` 没有这一步，不算。
4. **档案室「全部解锁」**：只写档案室的 `granted`，与成就无关；所有依赖档案的成就只读 `unlocked`。
5. **Mod 局**（待确认，第 14 节）：建议本局有用户 Mod 处于启用状态时标记 `mod`，与调试局同样处理；内置模块不算 Mod。`?nomod` 安全模式下照常。
6. **旧存档局**：读入没有本局追踪数据的旧存档时标记 `legacy`，「本局全程」类条件（E07、E10、E12、E16、P03）在这一局不可得，其余照常。
7. **只是本机记录**：和速通一样，本地数据可以被改，不做反作弊；界面和文档都写明。

## 6. 数据与存储

### 6.1 跨局记录 `wdfz3d_achievements_v1`

```text
{version:1,
 got:{<id>:{at:时间戳, diff, talent, day, mode:'normal'|'speedrun', legacy:0|1}},
 sets:{lethal:{}, rest:{}, notes:{}, anomalies:{}, talents:{}, hardEnds:{}, mazeExits:{}, mazeShadows:{}},
 migrated:1}
```

- 经 `GameStorage`（`adapters/storage.js`）读写；坏 JSON、版本不符按空记录处理并保留原文备份一次；未知 ID 丢掉；写失败只在内存里继续，不影响游戏。
- 不随存档、新局、死亡、通关、档案室「全部解锁」删除或修改；清除网站数据会一起清掉。
- **旧记录补发**（建议做，待确认）：首次启动时按现有可信记录补发能完全确定的成就，标 `legacy:1`、界面显示「旧记录」：已见结局 `wdfz3d_ends` → E01–E04、P01、H01；死亡档案 `unlocked`（不含 `granted`）→ N18、P05、H05；速通个人最佳与最近记录中 `finished` 的 → E17、P08（按记录里的毫秒和规则版本）、H10；`wdfz_pro` → N01。难度、天赋、本局全程、跨局集合类没有可靠来源，不补。

### 6.2 本局追踪（跟存档）

用 `GameModules.persistent('achievements', {save, load, reset})` 存在存档的 `d.mods.achievements`，不往 `S`、`RT` 加字段：

```text
{run:本局 ID, diff, talent, debug:0|1, mod:0|1, legacy:0|1,
 got:[id],             // 本局达成的成就（含以前已解锁、这一局又做到的），给积分计分用
 saved:0|1,            // 被药丸 / 免疫救过
 laughs:0,             // 第二天「笑一下」的次数
 faceWrong:0,          // 西小门答错次数
 inspections:{<day>:{early:0|1, late:0|1}},
 exams:{<day>:{pass:n, fail:n}}}
```

已有的本局状态（`RT.carTried`、`RT.anSeen`、`PAT.permanent`、`S.day`、`S.diff`、楼层草图）直接读，不复制。新局 `reset()`；读档先 `reset()` 再 `load()`；没有这份数据的旧档按 `legacy` 处理。

### 6.3 不做的

不联网、不云同步、不排行榜；建议不做「全部解锁」（第 14 节第 8 项待确认）；不提供玩家侧的「重置成就」（避免误删；调试面板提供，见第 8.4 节）。

- Wiki 只介绍成就系统本身：分哪几档、只记录没有加成、达成时有提示和分档音效、哪些情况不算（调试面板打开过的那一局等）。**不列成就名称和条件**（2026-11-03 用户要求，方法属于彩蛋）。

## 12. 与其他计划的关系

- 依赖的玩法仍有未完成的验收（天赋 M4 / M5、巡察与手机网络的自然试玩、恐怖体验的真人节奏、校园事件 M7）。成就只读事实、不改判定；这些玩法以后调整，只需改对应成就的条件或阈值，已达成的不收回。
- 与死亡档案室、速通、已见结局共用口径：死亡看 `unlocked`、结局看正常路线登记、速通看 `finished`。
- 隐藏结局精确时刻（《全死亡方式与结局CG重制、隐藏触发时刻校准》第 5 节）由原计划负责；成就只在结局成立后记录，不提供任何时刻提示。
- [积分、评级与通关记录](积分、评级与通关记录.md)（2026-11-03 立项）读本模块的「本局达成」集合按档位计分；本模块需要额外提供这个集合（第 6.2 节的 `run.got`），不读积分，也不因积分改变任何判定。

## 13. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 成就把恐怖游戏变成清单打卡 | 大部分普通成就在自然游玩中发生；没有次数刷取；提示排队、不在紧张时出现，音效短且不像游戏里有含义的声音 |
| 依赖隐藏数值、玩家无从判断 | 条件只用可观察的事实（结局、检查、异象、地点、选择），不用 SAN、违规、同化阈值 |
| 隐藏成就泄露秘密 | 解锁前不在 DOM、不计数；Wiki 不提；保密测试扩充；名称不包含触发时刻和步骤 |
| 速通阈值不合理（P08） | 15 分钟只是初值：实施前用自动路线测一次各路线最快可行时间，并参考真人记录再定；第一天自然运行约 13.4 分钟，《网安仙人》因无线接入与 600 运行秒的等待不可能进入这个阈值，P08 是「任一路线」 |
| 本局追踪与存档不同步 | 计数在事实发生时写入本局追踪，与现有自动存档节奏一起落盘；读档用例覆盖 |
| 提示与现有测试互相干扰 | 用独立元素，不改共用 `toast`；全量回归核对 |
| 本地记录被改 | 只作个人记录，不做反作弊（与速通一致） |
