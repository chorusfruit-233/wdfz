# 项目文档

这里收录《武大附中 · 里世界 3D》的产品、开发和测试文档。仓库根目录的 [README](../README.md) 是项目入口；面向玩家的 [游戏 Wiki](https://chorusfruit-233.github.io/wdfz/wiki/) 保持独立网页，游戏主菜单可以直接打开。

第一次了解产品，建议先读[游戏设计与机制总览](https://chorusfruit-233.github.io/wdfz/docs/game-design-overview.html)，再按需查阅完整产品对齐文档。前者解释机制如何共同构成游戏，后者保留精确规则、边界、历史与验收口径。
