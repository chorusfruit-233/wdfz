## 交付范围

- 学生会核对教学楼一楼本人座位的身份、坐姿和实际位置；开始后离座不可补签。有效请假在检查开始时锁定整场免检，不扣数值、不奖励、不续签、不新增缺席追踪，既有永久追踪保留。
- 新请假条持续 180 游戏分钟，旧截止时间不延长。士力架在 30 个运行秒内使步行/奔跑速度乘 1.5，奔跑不耗体力；隐藏、终端、乘梯、驾驶均计时，暂停不计时。旧铁胃存档确定性转无天赋。
- 教室向西布置黑板、讲台、课桌与同学，保留每层六班和南侧走廊；五层共 60 个独立前后门。瞄准选取与交互提示一致，起身从椅旁通道离座。
- 七个真实梯井连接 29 个门槛，踏步/平台/护栏/可走面同源；门槛处转换局部坐标，无选层菜单或淡出。楼层预览、梯段存档、按高度碰撞和巡察路径一起接入。钟楼既有旋梯保留。
- 普通 UI 与结算不再展示 SAN 数值、档位和校园风险标签；相关积分仅在显示层并入生存经历，旧记录和算法保留。身体反馈用平滑边缘变形、明暗和一条心跳节拍表达，并有标准/减弱/关闭扭曲、减少闪光设置。
- 声音字幕默认常开、可在设置关闭或选自动，与声音共用派发事件，静音或音频不可用时仍能显示；只描述可听见的来源、方位和远近。最多两条显示/八条排队，关键事件优先。加入灯管嗡声转移和关门后回应两个短演出；真实危险、暂停、离场或重新开门会中止相应演出。创意提案 H3–H5 未纳入本轮。

## 复现

在仓库根目录运行（需要 Python Playwright、Chromium；动态片段还需要 FFmpeg）：

```bash
python tools/check_modules.py
node tools/link_modules.cjs --check
python -m unittest discover -s tests -v
python tools/patrol_geometry.py
python tools/patrol_route.py
PATROL_AUDIT_DIR=docs/validation/双计划实施 python tools/patrol_runtime_audit.py
PATROL_AUDIT_DIR=docs/validation/双计划实施 python tools/patrol_chase_audit.py
python tools/school_sensory_preview.py
python tools/sensory_motion_probe.py
```

导航工具生成报告的具体文件名见工具输出；环境变量将本轮报告与历史验收隔离。截图支持 `--only 文件名`，感官工具支持 `--motion-only` 保留已测资源数据并重录动态画面。
