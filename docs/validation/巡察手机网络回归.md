# 巡察、手机网络与《网安仙人》回归记录

对应 [PR #29](https://github.com/chorusfruit-233/wdfz/pull/29) 与[实施计划](../plan/巡察者常驻、手机网络系统与网安仙人.md)。实施基线为 `9277684`，本地环境为 Python 3.12.14、Node.js 24、Playwright Chromium 软件 WebGL；路线生成使用 NetworkX 3.7。

## 可复现命令

```bash
python tools/check_modules.py
PYTHONPATH=tests python -m unittest test_campus_network_rules -v
PYTHONPATH=tests python -m unittest test_campus_network test_patrol_world test_network_lifecycle -v
PYTHONPATH=tests python -m unittest discover -s tests -v
python tools/patrol_runtime_audit.py
python tools/network_screenshots.py
```

导航产物重新生成：先 `python tools/patrol_geometry.py` 从实际房间／校园碰撞代理导出静态栅格，再 `python tools/patrol_route.py` 生成选定图的邮差闭环。重新生成后应审查产物差异并运行上面的导航与浏览器测试，不能用旧报告证明新地图。
