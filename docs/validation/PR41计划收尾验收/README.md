## 收尾修正

- 「念错了」演出误把单参数分段值传给三参数平滑函数，导致门位置出现 NaN；修正调用，并覆盖全部死亡模型的有限数值检查。
- 为不受雾影响的贴图预热对应着色器，消除第一次播放该演出新增编译的卡顿。
- 巡察报点区从 8 个增至 9 个后，更新旧断言，并验证广播站调查点与其余八点均可达。
- 两项异步切场测试的 4–5 秒墙钟期限在并发软件 GPU 下过短。诊断确认状态与完成回调正常后，上限改为 20 秒，仍用真实动画帧验证切场和收尾，不改游戏计时。
- 重新取景，避免离校人群挡住登记簿、穿过关闭车道门，以及前排建筑遮住教学楼；结尾逐层熄灯可见。手机竖屏话筒面板避开全屏键，390×844、844×390、667×320、480×320 均验证关闭按钮可点及触屏取消停播。
