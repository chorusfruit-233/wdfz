# 无线破解位置暴露验证

2026-11-03，基于 main `8f1378b`。实现按用户要求追加的「无线破解每 15 秒向巡察者暴露一次静态位置」。

## 最终行为

- 使用破解实际累计的运行秒，在 15、30、45……秒采样场景、坐标与脚高；更新同一个巡察者的单份情报，不增加实体、不直接锁定、不变成永久追踪。
- 巡察者通过原导航调查快照位置，玩家随后未被看见的移动不更新情报。抵达后搜索 3 秒，接近预警不消耗这 3 秒；仍未发现玩家时恢复原任务。椅子等碰撞附近的目标按导航可行走点调查，快照本身不改写。
- 永久追踪与实际目击追逐／丢失搜索优先，其后为无线情报、办公室区域队列及柜子记忆。调查不受座位、假条、外出许可和普通敌对时段豁免；原有视线、接近预警、瞬移距离、符纸、检查现场等待仍生效。暴露时在柜子里只记住当时那一个柜门，未目击的换柜不泄露。
- 手机收起仍破解。主动暂停、断电、丢弃设备和世界暂停不累计；续跑、读档接续剩余间隔，不重置、不补发。恰在 15 秒边界完成／断电时接受该次情报，之后下载和服务器任务不再暴露新位置。
- 暂停或完成不撤回已发情报；符纸消灭期间保留，真正救回、预知梦和新局清除。旧存档缺少情报时按空值恢复，不重抽破解目标或补送电量。规则版本升级为 3，存档结构仍兼容版本 1。
- 手机无线页显示规则与下次暴露倒计时，并在暴露时通知玩家。Wiki、产品对齐与原计划同步。原《网安仙人》实录保留录制版本，明确不作为本机制下的自然通关证据。
