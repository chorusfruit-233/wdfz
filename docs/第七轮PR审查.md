## 几何审查的范围和限制

使用 `python tools/clip_audit.py` 扫描 **30 个室内场景和室外**，默认均衡画质。报告在 [`tools/clip_report.json`](../tools/clip_report.json)，字段如下：

- `scope.quality`：0 流畅、1 均衡、2 精细、3 超精细。
- `scope.rooms`：此次实际扫描的场景。局部扫描即使没有候选，也不能代表全校没有问题。
- `counts`：各类型候选的数量；未出现的类型为 0。
- `issues`：位置、物件归属和类型等明细。

初次审查在三档中发现 906 条 `walk` 和 904 条 `patrol` 候选；与 `main` 的 `15a6ca2` 比对，这些是既有问题。后续整合模型占地和细网格路径后，报告重新生成。最终扫描增加可达性和同学坐姿检查，不能把前后的数字当作完全相同的检查范围；也不能把零候选当作所有穿模均已解决。

家具碰撞最终来自独立于画质分段的解析尺寸。可达性按打开所有门的条件检查，使用和玩家相同的圆形站立判定；这不会验证钥匙顺序、剧情条件或完整通关路线。

审查采用采样与形体判定，并排除部分正常嵌装；它不完整覆盖动态人物、手持物、镜头与墙体，也不验证完整游戏路线。钟楼净空回归使用独立的实际模型射线，避免只依赖静态候选报告。

重跑或只检查局部时可指定输出，保留仓库内的全量报告：

```bash
python tools/clip_audit.py
python tools/clip_audit.py bell1 dorm1 garage1 --out /tmp/clip-local.json
python tools/clip_audit.py --quality 2 --out /tmp/clip-high.json
```

候选项本身不使命令失败；非法参数、浏览器错误或扫描异常会返回非零退出码。

- 修复切档改变树木/灌木布局、模型顶点分段改变家具占地的问题；四档玩法和碰撞一致。
- 切档保持角色位置、门、异象计时、车库追逐、巡察与同学堵门状态；更新材质尺寸和当前人物几何体，释放旧网格、贴图、目标与阴影。
- 超精细实际渲染通过 Shader/WebGL 错误检查；手持物使用独立透明目标，保留世界深度用于接触遮蔽。
- 补车库怪物大步移动不能越过薄障碍的检查；巡察者实际移动会重新检查障碍，防止关门后继续沿旧路径穿过。
- 开局座位等待淡入完成后检查起身，避免把尚未建好的场景当成成功；性能截图也等待真实房间模型出现。
- 设备限制：自动化使用 Chromium 软件 WebGL。断网本地资源启动可测；受管理策略阻止的 `file://` 测试明确跳过，不绕过策略。
