## 几何审查的范围和限制

使用 `python tools/clip_audit.py` 扫描 **30 个室内场景和室外**，默认均衡画质。报告在 [`tools/clip_report.json`](../tools/clip_report.json)，字段如下：

- `scope.quality`：0 流畅、1 均衡、2 精细。
- `scope.rooms`：此次实际扫描的场景。局部扫描即使没有候选，也不能代表全校没有问题。
- `counts`：各类型候选的数量；未出现的类型为 0。
- `issues`：位置、物件归属和类型等明细。

本次全量扫描保留了 906 条 `walk` 和 904 条 `patrol` 候选，主要涉及座位、办公工位和机房家具。它们需要结合截图、角色半径和实际移动逐项核实，不能把候选数当作已经确认的缺陷数，也不能把几何扫描的空结果当作所有穿模均已解决。相关后续工作列在[计划文档](计划-穿模超精细与引擎重构.md) A4–A7。

三档画质均扫描了 31 个场景，结果相同。使用同一审查器扫描 `main` 的 `15a6ca2` 时，也得到 906 条 `walk`、904 条 `patrol`；按类型、场景与物件归属比对，无新增或减少。这些是既有候选，不是本次调整引入的新候选。其余类别在本次三档扫描中均为 0，但仍受下述检查能力限制。

审查采用采样与形体判定，并排除部分正常嵌装；它不完整覆盖动态人物、手持物、镜头与墙体，也不验证完整游戏路线。钟楼净空回归使用独立的实际模型射线，避免只依赖静态候选报告。

重跑或只检查局部时可指定输出，保留仓库内的全量报告：

```bash
python tools/clip_audit.py
python tools/clip_audit.py bell1 dorm1 garage1 --out /tmp/clip-local.json
python tools/clip_audit.py --quality 2 --out /tmp/clip-high.json
```

候选项本身不使命令失败；非法参数、浏览器错误或扫描异常会返回非零退出码。
