# 测试与回归检查

在仓库根目录运行操作回归检查：

```bash
python -m pip install playwright
python -m playwright install chromium
python -m unittest discover -s tests -v
```

若已安装系统 Chromium，可通过 `CHROMIUM_EXECUTABLE` 指定路径；测试会自动查找 `chromium`。

测试自动启动本地 HTTP 服务，使用 Chromium 软件 WebGL，覆盖首页与旧链接、Wiki 的桌面和触屏入口及返回游戏、原生全屏、WebKit 兼容分支、拒绝后重试、鼠标锁定、触屏接管、真实双指操作、触摸取消、面板与暂停恢复、移动速度和界面滚动，以及机房贪吃蛇的触屏操作与退出、士力架与体力、《先辈》时间窗、钟楼旋转楼梯与考试模式，以及第二轮优化：背包刷新、翻找读条、作息、异象不重复、陷阱选项地点、巡察者（锁定、躲柜子、背对逃脱、符纸）、校长办公室钥匙、传送门真结局、垃圾桶假结局、买饭和售货机、不知名药丸、手持模型、结局演出与跳过。另覆盖钟楼楼梯和平台的存档恢复、旧存档兼容、疾跑状态、考试异象预告、保安岗手电的满包重试及车库出口、自动存档与结局记录、矮屏和触屏返回主菜单的布局。WebKit 接口及主屏幕模式通过模拟接口验证；未替代实体 Safari/iPhone 测试。
