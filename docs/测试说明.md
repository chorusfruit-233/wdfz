# 测试与回归检查

以下全量命令包含穿模检查。Claude 仅在更新建模或玩法时运行其中的穿模检查；其他更新选择不包含穿模检查的相关测试。安装依赖和运行操作回归检查的命令如下（在仓库根目录执行）：

```bash
python -m pip install playwright
python -m playwright install chromium
python -m unittest discover -s tests -v
```

若已安装系统 Chromium，可通过 `CHROMIUM_EXECUTABLE` 指定路径；测试会自动查找 `chromium`。

测试自动启动本地 HTTP 服务，使用 Chromium 软件 WebGL，覆盖首页与旧链接、Wiki 的桌面和触屏入口及返回游戏、原生全屏、WebKit 兼容分支、拒绝后重试、鼠标锁定、触屏接管、真实双指操作、触摸取消、面板与暂停恢复、移动速度和界面滚动，以及机房贪吃蛇的触屏操作与退出、士力架与体力、《先辈》时间窗、钟楼旋转楼梯与考试模式，以及第二轮优化：背包刷新、翻找读条、作息、异象不重复、陷阱选项地点、巡察者（锁定、躲柜子、背对逃脱、符纸）、校长办公室钥匙、传送门真结局、垃圾桶假结局、买饭和售货机、不知名药丸、手持模型、结局演出与跳过。另覆盖钟楼楼梯和平台的存档恢复、旧存档兼容、疾跑状态、考试异象预告、保安岗手电的满包重试及车库出口、自动存档与结局记录、矮屏和触屏返回主菜单的布局；以及满包重试关键物品、门开启后的读档与再进入、躲柜时碰撞和跟丢、追击寻路和跨局读条清理。WebKit 接口及主屏幕模式通过模拟接口验证；未替代实体 Safari/iPhone 测试。

第三轮新增：精细画质的实时阴影与切回低档、窗光光柱落地、灯下光斑、室外不残留室内光影；雨丝数量、溅水圈、积水、闪电与清理；蛾群逼近但不贴住镜头、落粉与清理；脚步地面判定（草地、球场、道路、车库、瓷砖）、灯管噼啪与新声音接口；巡察者造型网格。

第三轮评审补充：在同一室内场景切换流畅、均衡和精细画质，验证窗光、灯斑与旧网格清理；在远离原点的室外场景验证关闭实时阴影后的光源方向。

混合输入检查模拟具有触摸能力的桌面设备，验证鼠标锁定后的视角移动、鼠标不会触发触屏摇杆，以及鼠标与触摸之间的切换。真实触屏笔记本仍需实机验证。

产品对齐修复：检查亮度刷新、手电与手机交叉开关及移除后的状态、光源和活动冷却读档及旧存档默认值；检查罗盘、护目镜和硬币满包 / 重复时的来源重试；验证「天生免疫」与药丸优先级、存档及致命异象；核对熄灯 HUD、调试时间和讲台字幕。

界面重构：随身手册页签切换与开合、背包详情的使用 / 快捷栏 / 丢弃、选择框数字键、触屏交互键显示当前动作与手册键、处理较慢的触屏操作只触发一次、竖屏字幕宽度；药片持续回复、士力架 30 秒、白天曝光、一天自由时间不少于 10 分钟。

第七轮评审新增：手册被暂停面板替换后遮罩和字幕恢复；320×568 与 320×480 竖屏快捷格不越界、不压摇杆且可触摸使用；钟楼开口超过半圈时的实际模型净空射线、顶层空洞碰撞，以及按玩家碰撞完成上下楼；药片剩余时间的读档、面板暂停和旧档默认值。审查工具另检查错误房间不会覆盖原报告，以及空的局部扫描仍记录范围和画质。

## PR #7 引擎与几何回归

```bash
python -m unittest discover -s tests -v
PYTHONPATH=tests python -m unittest test_engine test_geometry -v
python tools/clip_audit.py --quality 3 --out /tmp/clip-ultra.json
python tools/engine_compare.py --before /path/to/old-checkout --frames 3
```

`tests/browser_case.py` 提供共用浏览器夹具；`test_engine.py` 验证五档设置（含「真实」）、切档状态、碰撞一致性、资源释放、实际超精细渲染、低帧率提示、离线资源和相机；`test_geometry.py` 验证占地、巡察路径、全校候选、可达性、手持物、起身和车库大步移动。几何工具接受 0–4 五档，报告始终包含范围。

管理策略禁止 `file://` 时，仅对应检查标记跳过，并保留错误原因。另一项禁网测试由浏览器请求处理器读取仓库内资源，启动真实主页并渲染超精细场景；它验证资源自足，不替代被策略阻止的文件协议检查。

性能工具固定 960×540、DPR 1，在冻结的教室/校园场景里采样渲染并同步读回像素；数据含绘制次数、三角形、资源数量和耗时。软件 WebGL 的结果不能代表真实设备帧率，截图也不构成自然游玩通关证据。

`test_model.py` 保留最新建模内核和氛围回归：压缩顶点、隐藏面剔除、场景缓存、只替换门扇、平滑曲面/新图元、流畅档顶点预算（按实际绘制的顶点算，实例乘个数）、走廊人影。所有档位使用同一 Three.js 后端，不再包含第二引擎出图或引擎切换测试。

2026-10-29 合并前结果：全量 139 项（138 通过、1 项 `file://` 环境策略跳过）；另补 DPR 2 往返切档专项 1 项通过，共 140 项检查、139 通过、1 跳过。四档各 31 个场景的全量几何扫描均为零候选。完整证据与限制见[第七轮 PR 审查](第七轮PR审查.md)。

## 建模重做（PR #11）

```bash
PYTHONPATH=tests python -m unittest test_assets test_asset_batching test_model test_engine -v
python tools/clip_audit.py --quality 4 --out /tmp/clip-real.json
python tools/model_stats.py /tmp/model-stats.json
```

- 浏览器夹具的 `set_quality(page, q)` 换画质后等这一档的模型包读好（包按需异步读，读好后当前场景重建一次），再做断言。
- `test_assets.py`：触屏设备读不含画质的旧设置时，开局读的模型档和实际画质一致；开局模型包读不到时停在菜单，键鼠和触屏点「重试」后家具和碰撞恢复；游戏中换画质读包失败时继续用已有的一档，可以重试，回调不会越积越多；手电、伞、手机随画质换模型并释放旧几何体；连续换画质时迟到的包只应用一次；四个模型包的解压结果和 zlib 一致，截断的数据会报错而不是一直等。
- `test_asset_batching.py`：室外稀疏合批后的位置、染色、贴图坐标和实例化时一致，透明材质仍单独实例化；流畅、均衡档室外的网格数、两个固定机位的绘制次数和三角形有上限，流畅档实际绘制的顶点在 45 万以内。
- `test_engine.py` 的「真实」档用例把房间方块和 Blender 模型的三角形分开比；切档用例等模型包读好再比人形的细致程度。`test_geometry.py` 里人形的碰撞代理贴着身体，坐着的同学不和课桌相交；超精细档的碰撞检查也等模型包读好。
- 建模统计：`tools/model_stats.py` 五档都量，实例化的按个数算，结果见[建模统计](建模统计.md)。

2026-10-30 PR #11 合并后（main `13c1c79`）：全量 155 项全部通过，没有跳过（本环境的 Chromium 允许 `file://`）；五档各 31 个场景的全校穿模审查均为零候选。
