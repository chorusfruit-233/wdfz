# 测试与回归检查

在仓库根目录运行操作回归检查：

```bash
python -m pip install playwright
python -m playwright install chromium
python -m unittest discover -s tests -v
```

若已安装系统 Chromium，可通过 `CHROMIUM_EXECUTABLE` 指定路径；测试会自动查找 `chromium`。

测试自动启动本地 HTTP 服务，使用 Chromium 软件 WebGL，覆盖首页与旧链接、Wiki 的桌面和触屏入口及返回游戏、原生全屏、WebKit 兼容分支、拒绝后重试、鼠标锁定、触屏接管、真实双指操作、触摸取消、面板与暂停恢复、移动速度和界面滚动，以及机房贪吃蛇的触屏操作与退出、士力架与体力、《先辈》时间窗、钟楼旋转楼梯与考试模式，以及第二轮优化：背包刷新、翻找读条、作息、异象不重复、陷阱选项地点、巡察者（锁定、躲柜子、背对逃脱、符纸）、校长办公室钥匙、传送门真结局、垃圾桶假结局、买饭和售货机、不知名药丸、手持模型、结局演出与跳过。另覆盖钟楼楼梯和平台的存档恢复、旧存档兼容、疾跑状态、考试异象预告、保安岗手电的满包重试及车库出口、自动存档与结局记录、矮屏和触屏返回主菜单的布局；以及满包重试关键物品、门开启后的读档与再进入、躲柜时碰撞和跟丢、追击寻路和跨局读条清理。WebKit 接口及主屏幕模式通过模拟接口验证；未替代实体 Safari/iPhone 测试。

第三轮新增：精细画质的实时阴影与切回低档、窗光光柱落地、灯下光斑、室外不残留室内光影；雨丝数量、溅水圈、积水、闪电与清理；蛾群逼近但不贴住镜头、落粉与清理；脚步地面判定（草地、球场、道路、车库、瓷砖）、灯管噼啪与新声音接口；巡察者造型网格。

第三轮评审补充：在同一室内场景切换流畅、均衡和精细画质，验证窗光、灯斑与旧网格清理；在远离原点的室外场景验证关闭实时阴影后的光源方向。

混合输入检查模拟具有触摸能力的桌面设备，验证鼠标锁定后的视角移动、鼠标不会触发触屏摇杆，以及鼠标与触摸之间的切换。真实触屏笔记本仍需实机验证。

清华水杯：触发条件（只在三栋五层楼外墙边、柱廊下不触发、伞不算遮挡、室内不触发），原地不动被砸死，躲开后不死、扣 SAN 并留下地上的杯子。

产品对齐修复：检查亮度刷新、手电与手机交叉开关及移除后的状态、光源和活动冷却读档及旧存档默认值；检查罗盘、护目镜和硬币满包 / 重复时的来源重试；验证「天生免疫」与药丸优先级、存档及致命异象；核对熄灯 HUD、调试时间和讲台字幕。

产品对齐决定：检查运动场地判定、宿舍违规增长、连续日数和跨日冷却、旧冷却迁移、随机天赋池、硬币引诱及到期、调试密码；验证异象选择的 5 秒随机超时、预警范围，以及车库怪物、预报、隐性倒计时和室内异象的读档恢复。

手写清单第三批：一天时长 10–20 分钟、违规满不死且不能请假、请假条（不涨违规、巡察者不管、到时结束）、手机纸飞机（背包鼠标和触屏入口、世界照走、人不动、体力与道具计时、奖励冷却读档、异象 / 选择 / 死亡打断）、拍肩笑脸变体的两种结果及难度倍率、自言自语随 SAN 换台词。额外检查宣传片脚本不会清空非空的自定义输出目录。

界面重构：随身手册页签切换与开合、背包详情的使用 / 快捷栏 / 丢弃、选择框数字键、触屏交互键显示当前动作与手册键、处理较慢的触屏操作只触发一次、竖屏字幕宽度；药片持续回复、士力架 30 秒、白天曝光、一天自由时间不少于 10 分钟。

穿模与超精细（`tests/test_engine.py`）：全校穿模审查（互相插入、穿墙、碰撞不符、巡察者擦碰、走不到、坐着的同学）为 0；超精细档抽查几间房和室外；家具碰撞跟着模型、座位有碰撞且坐下不被挪走；圆形精确碰撞贴墙滑动；镜头近裁剪面碰不到墙；巡察者路径离家具不少于 0.27 米；四档画质参数表、菜单和设置；低帧率降档提示只问一次；Babylon.js 后端能初始化、画出非纯色画面、手动切回和加载失败都退回 Three.js；手持物单独一遍画。

建模内核重写（`tests/test_engine.py`）：建模工具输出的法线是 8 位、颜色是 8 位或 16 位、索引是 16 位；贴地朝下、贴吊顶朝上的面只在要求时才不建；第二次进同一层楼、第二次出门直接用上次建好的；开门只换门扇那一块，整层楼不动。

辅助工具（不在回归里跑，需要时手动用）：

```bash
python3 tools/clip_audit.py            # 全校穿模审查，结果写到 tools/clip_report.json
python3 tools/clip_audit.py teach1 out # 只查某几间房 / 室外
python3 tools/clip_view.py 输出目录 teach2:-20.5:0.75:-4.25:1.4:0.3   # 给某个点拍照（房间:x:y:z:距离:朝向）
python3 tools/engine_compare.py 输出目录                           # 两个引擎画同一个画面并比较亮度
python3 tools/model_stats.py [输出.json]                         # 四档画质的顶点、三角形、缓冲区大小、建模耗时和每帧绘制次数
```

Babylon.js 在无头浏览器的软件渲染下第一次编译着色器要 1–2 秒，测试里会等它准备好；毫秒数只能比相对快慢，不代表显卡上的帧率。
