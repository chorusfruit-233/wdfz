# 调试面板说明

游戏中按 **F2**，或在暂停菜单点击「调试」并输入密码，可以打开调试面板。触屏设备从暂停菜单进入。密码校验仍在 `game3d/js/dev.js` 中；每次打开都需要输入。F2、Esc 或右上角关闭按钮可关闭面板。

面板每次打开时默认暂停游戏模拟，点击「继续模拟」可在面板打开期间继续推进。真实时间的选择倒计时和画面演出不会因此暂停。如果原本打开了暂停菜单或其他会暂停游戏的界面，面板会显示「游戏菜单已暂停」；关闭调试面板后仍需从原界面恢复游戏。

## 状态

状态页显示当前 SAN、体力和上限、违规、同化、游戏时钟、地图坐标及当前异象。准星探测检查室外场景；室内或没有命中时显示「—」或相应提示。

「设定数值」接受 0–100，并按当前 SAN 裁剪体力上限。SAN 设为 0 或同化设为 100 后，继续模拟时会按游戏规则触发死亡。恢复 SAN / 体力会把两者恢复到 100。复活会关闭死亡画面，SAN 为 0 时恢复到 45，同化满值回落到 86；已经消耗的道具和删除的存档不会自动恢复。

## 场景

室内和室外列表支持按名称或 ID 搜索，没有匹配项时传送按钮不可用。传送会结束当前巡察并退出柜内躲藏、楼梯及翻找状态。室内传送沿用游戏的自动存档，室外传送不会立即自动存档。

时间按钮每次调整 30 游戏分钟，仍会触发适用的跨日和课表规则。时段不再允许巡察时，现有巡察会结束。

## 事件

- 异象列表支持搜索；直接触发跳过正常出现条件，会先结束当前异象。结束现有异象仍可能执行它原本的结算。
- 画面演出可播放融入、雨和镜面的后处理效果，结束后自动恢复。
- 死亡效果「预览」只播放视觉和声音，不杀死角色、消耗救命道具或删除存档；3.5 秒后清理。为避免覆盖异象画面，正在发生异象时需要先结束它。
- 「触发实际死亡」会先确认，之后按真实死亡规则处理救命道具、预知梦和存档，可能删除存档。调试无敌不会阻止此测试，但按钮状态会保留。

## 工具

快跑、无敌、翻找读条和假正常开关的当前状态会高亮；柱廊顶、花园牌、连廊和围墙按钮在对应部分被隐藏时高亮。快跑、无敌、翻找读条和场景显示设置在关闭面板后继续生效，直到再次切换或刷新页面。

「触发走廊灯异象」按直接触发异象处理。「重看前情提要」会确认后开始新游戏，可能覆盖当前自动存档。

## 验证

在仓库根目录运行：

```bash
PYTHONPATH=tests python -m unittest -v test_dev_panel
python -m unittest discover -s tests -v
```

浏览器测试覆盖键盘和触屏模拟、焦点与暂停状态、筛选、传送、数值范围、预览及存档边界。模拟浏览器不代表实体手机的输入、性能或视觉效果。
