# 调试面板说明

游戏中按 **F2**，或在暂停菜单点击「调试」并输入密码，可以打开调试面板。触屏设备从暂停菜单进入。密码校验仍在 `game3d/js/dev.js` 中；关闭后重新打开需要输入，收起后再展开不用输入。F2 或右上角关闭按钮可关闭面板；焦点在面板内时，Esc 也可关闭。

按住标题栏上的「按住拖动」区域，可以用鼠标或手指移动窗口；在面板内容区上下滑动仍是滚动内容。点击「归位」可将窗口移回默认位置，桌面 / 竖屏为左上角，触屏横屏为中间。键盘用户可以用 Tab 选中标题栏，再用方向键移动，按住 Shift 加快移动，或按 Home 归位。窗口位置在本次页面会话中保留，刷新页面后恢复默认。

点击标题栏「收起」，窗口变成一个 **18 像素的小圆点**，首次出现在屏幕右侧中间。圆点周围有 44 × 44 像素的透明触摸区域，点击展开，按住拖动；拖动后松手不会误展开。键盘选中圆点后，方向键移动，Home 归位，回车或空格展开。圆点呈绿色表示运行，金色表示暂停或当前不能正常游玩。收起与展开保留当前页签、搜索内容、滚动位置和调试暂停状态，窗口与圆点分别记住位置；结束本局会一起关闭。

手机上自动采用紧凑布局：宽度最多 300 像素，竖屏高度最多约 62%，横屏最多约 74%；缩减标题、间距和说明占用，按钮仍至少 44 像素高，输入框保持 16 像素字号。横屏时窗口默认放在中间，为两侧的摇杆和交互键留出位置；手动拖动过的位置仍保留。旋转屏幕、调整窗口大小或弹出软键盘时，窗口和圆点会限制在可见范围内；内容区可独立滚动。窗口外仍可操作游戏：点击或触摸画面后可以移动、环视、交互、打开背包和切换全屏。鼠标被游戏捕获后，按 **Alt**（或 ` 键）只放出鼠标、游戏不暂停，可以直接点调试窗口，点一下画面（或再按 `）收回；Esc 仍是放出鼠标并暂停游戏，调试窗口继续显示。面板内的输入、按钮、拖动和滚动不会触发游戏快捷键。

面板默认不冻结游戏。需要检查静止场景时，点击「暂停游戏」；点击「继续游戏」恢复操作。调试暂停包括当前异象和随机环境幻觉的计时；真实时间的选择倒计时和主动触发的死亡 / 画面演出不会因此暂停。从暂停菜单打开时保留原暂停状态，可以直接点击面板的「继续游戏」恢复游玩，窗口仍保持打开；若直接关闭面板，则仍返回原暂停菜单。其他选择、前情提要或电脑小游戏仍保留各自的暂停规则，「继续游戏」不会擅自关闭它们。

## 状态

状态页显示当前 SAN、体力和上限、违规、同化、游戏时钟、地图坐标及当前异象，还显示巡察阶段 / 倒计时、检查剩余时间 / 排队数量及电梯 / 驾驶状态。准星探测检查室外场景；室内或没有命中时显示「—」或相应提示。

「设定数值」接受 0–100，并按当前 SAN 裁剪体力上限。SAN 设为 0 或同化设为 100 后，继续模拟时会按游戏规则触发死亡。恢复 SAN / 体力会把两者恢复到 100。复活会关闭死亡画面并恢复死亡前的镜头方向与高度偏移，SAN 为 0 时恢复到 45，同化满值回落到 86；已经消耗的道具和删除的存档不会自动恢复。

## 场景

室内和室外列表支持按名称或 ID 搜索，没有匹配项时传送按钮不可用。传送会关闭当前选择，结束正在发生的异象和巡察，移除拍肩事件结束后残留的笑脸，并退出柜内躲藏、楼梯及翻找状态。异象按正常结束规则结算，例如未处理的名单仍会增加违规；尚未发生的异象预报按原规则保留。室内传送沿用游戏的自动存档，室外传送不会立即自动存档。

时间支持 ±30 游戏分钟、指定时分，以及早晨、夜间、两次检查前的快捷时刻。可设定范围为 07:20–次日 00:59；01:00–07:19 属于游戏自动跳过的时段，拒绝输入。调整沿用游戏的推进 / 回拨函数，跨日和定时检查规则照常生效，时段不再允许巡察时现有巡察结束。回拨不撤销已发生的事件或已领的奖励。电梯、驾驶、检查或排队检查期间禁止调时，避免破坏正在运行的流程。

## 物品

新增独立物品页，可按名称或 ID 搜索全部物品，查看描述、是否持有、背包占用和当前快捷栏。添加物品遵循八格容量且不重复；满包时添加按钮禁用。移除沿用正常背包逻辑，同步取消手电 / 雨伞手持状态与对应快捷栏。已持有的物品可直接放到快捷栏 1 或 2。死亡或未开局时不可修改。

物品操作改变当前局，之后的正常自动存档会保存这些变化；调试操作不会自动清空背包或解锁整条剧情。

## 事件

- 异象列表支持搜索；直接触发跳过正常出现条件，会先结束当前异象。结束现有异象仍可能执行它原本的结算。
- 巡察可手动开始预警或结束当前巡察，遵循当前地点和时段资格、躲藏和请假规则；结束后仍可能按正常间隔再次出现。
- 学生会可手动开始实际检查，也可取消当前及排队检查。手动检查立即按当前位置、移动和注视行为结算，不代替当天定时检查；取消不执行结束奖惩，检查中已经扣除的数值不回退。异象、巡察、检查、选择、课堂互动及电梯 / 驾驶等流程不会被新巡察或手动检查叠加覆盖。
- 画面演出可播放融入、雨和镜面的后处理效果，结束后自动恢复；退出或开始新游戏时会清除尚未结束的预览。
- 死亡效果「预览」只播放视觉和声音，镜头演出使用独立的渲染状态，不修改玩家的方向或高度；预览期间玩家的操作会保留。不杀死角色、消耗救命道具或删除存档；按效果时长自动清理，至少保留 3.5 秒。为避免覆盖异象画面，正在发生异象时需要先结束它。「停止调试预览」可提前清除死亡预览与画面后处理，不终止真实异象或真实死亡。
- 「触发实际死亡」会先确认，之后按真实死亡规则处理救命道具、预知梦和存档，可能删除存档。调试无敌不会阻止此测试，但按钮状态会保留。
- 「氛围」一节：「开始五分钟切片」按安静 → 先听后见 → 危险操作 → 兑现或落空 → 余韵五个节拍跑一遍并关闭面板：先听后见是收音机、两次换方向的脚步和一声什么都没有的门响，兑现时一半概率触发现有的走廊灯异象、一半只是骤静落空，余韵在附近留一张纸条；不新增致死机制。「来一声假威胁」播一个有方位的假威胁，仍受惊吓预算限制（开局 60 秒内、刚响过或别的事件进行时不出声）。

## 工具

快跑、无敌、翻找读条和假正常开关的当前状态会高亮；柱廊顶、花园牌、连廊和围墙按钮在对应部分被隐藏时高亮。快跑、无敌、翻找读条和场景显示设置在关闭面板后继续生效，直到再次切换或刷新页面。

「触发走廊灯异象」按直接触发异象处理。「重看前情提要」会确认后开始新游戏，可能覆盖当前自动存档。

运行诊断显示当前输入方式、鼠标捕获状态、游戏输入是否允许、画质、窗口大小及 GPU 几何体 / 纹理 / 着色程序数量。它们是资源计数，不是显存大小或性能评分。

「生成诊断文本」提供可选择复制的只读 JSON；「下载诊断 JSON」保存文件。报告包含当前位置、角色数值、背包、事件概况、输入与画质状态、调试开关及最近 20 条调试反馈，面板显示最后 5 条。读取报告不会改动角色或存档，不依赖剪贴板权限、网络服务或控制台。报告用于内部排查，可能包含尚未探索到的物品 / 事件名称，不是存档，也不提供导入功能。

## 验证

在仓库根目录运行：

```bash
PYTHONPATH=tests python -m unittest -v test_dev_panel
python -m unittest discover -s tests -v
```

浏览器测试覆盖鼠标、键盘和触屏模拟的拖动、归位、滚动与窗口边界，以及焦点与暂停状态、筛选、传送、数值范围、预览及存档边界。模拟浏览器不代表实体手机的输入、性能或视觉效果。
